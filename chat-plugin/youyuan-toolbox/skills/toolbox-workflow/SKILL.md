# 疣螈工具箱

使用本插件关联的 MCP 服务：https://toolbox.youyuanqi.dpdns.org/mcp/oauth/linux-server。

1. 先检查服务连接及当前公开的工具和参数。仅使用实际发现的工具，不假设任何游戏、文件或设备功能存在。
2. 根据用户的目标调用相应工具。已经授权且必要的操作持续完成，无需重复询问。
3. 遵循用户当次授权范围；不得因为服务提供某项能力而扩大操作范围。未明确授权远程设备控制时，不连接或控制电脑。
4. 修改现有代码或配置时，先读取当前内容，保留已有功能；根据工具实际能力保存恢复副本并验证修改结果。
5. 如认证失败，通过宿主的 OAuth 连接流程登录自己的游园账号并授权。不要把密钥写入技能、插件文件、日志、工具结果或回复。不要将密钥拼入网址。
6. 服务报错、工具缺失或访问拦截时，说明具体阻碍，不伪造成功或已完成验证。简洁报告实际完成的内容和未完成项。

7. 本服务连接的是 Linux 机器人执行端。先调用实际发现的 api_bot_status 进行只读验证，再按需读取开发文档资源和插件源码。工具列表或网页介绍存在，不等于工具已挂载或执行成功。
8. 插件读写后必须读回；运行或重载后检查实际状态。不得编造 Linux shell、Docker 或系统管理工具，以当前 tools/list 为准。
