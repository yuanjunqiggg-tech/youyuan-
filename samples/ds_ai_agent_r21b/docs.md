# 多功能插件 R21B · 游园常驻适配

一个 ds_ai_agent 插件保留原菜单、领地、公会、死亡检测、AI、公告与 FUNCTION 业务。
main.lua 仅加载 modules/core.lua 一次；modules/native_bridge.lua 对接游园原生链。
源码仍完整可读写，AI工作区可跨文件编辑；不再把1.2MB源码塞进config/docs缓存。

## FUNCTION
两份原文TXT在command_txt/：药水系统.txt、雪球菜单_综合功能.txt。
首次登记到命令链但默认停止，避免导入即给在线玩家物品/改规则。原已登记且启用的用户文件保留启用选择。
游戏内 .function 管理原菜单，或 .命令选择 / .链；网页命令链使用同一执行器。
2,0,0 20 是整段20Hz；. 分出并行的独立段；1,0,0启动一次；!结束。
前缀初始化脉冲先提交，随后循环段独立启动。无条件走Fast，真实条件与它的前条需要回执。
只在首次导入/修改时读TXT和编译；每轮不读注册表、不解析字符串、无需计分板门控低Hz。
Fast提交数量不是服务器成功数量；不能保证多条命令同一服务器Tick执行。
停止插件会停止它已管理的链；用户在原生界面单独新建的其他链不受影响。
文件仍位于插件数据目录 command_txt/，编辑会同步原生命令链，保留原文。

## AI与提示词
保留R21B六份 ai_prompts/ 原文，按任务读取并缓存；数据目录的用户修改版优先。
聊天 AI 内容为公开回复，ai 内容为私聊；保留[Ds]与本次/窗口Token累计。
原有“正在思考中”在最外层聊天入口立即用Fast发送，不等待旧包装层读档和预测；不新增阶段提示。
Token使用API返回usage，重试亦计入；不伪造计费价格。无内置API密钥。
提示词修改后热重载插件，或调用plugin_api.reloadPrompts；任务重新读取后使用新提示词。

## 公告
保留R21B内容与刷新逻辑；常驻内存保存上一版，仅删除旧行/更新变化行，不每轮拆建计分板。
本适配不宣称游戏死亡/击杀者各协议均已实测；实际能力受服务器与回包影响。
Linux为默认部署环境，C++宿主仍未接入；本次热点用原生Go无需添加额外Python/C++插件。
完整框架API见软件开发文档/技能command-chain，SDK三语言共享chains接口。

## R21B 测试适配
保留1.0.74全部业务和六份提示词、两份原文TXT。时间函数使用UTC格式基准再偏移8小时，避免宿主时区重复偏移。
CommandOutput不再充当时钟触发死亡查询，避免查询回包递归放大；保留背包回包与周期定时器。
AI最外层首先Fast提交原“正在思考中”，本轮重复begin只更新一次状态。删除源码中的内置私人密钥，用户配置优先。
死亡Text/PlayerLocation/PyRpc/ActorEvent/UpdateAttributes/SetActorData处理器保留。未知实体不猜成唯一在线玩家。
协议解析模拟测试不能代替真人死亡、复活和屏幕显示验收。两份游戏TXT默认停止，不向现有服自动派发物品。
普通Chat需先安装并OAuth授权“疣螈工具箱”，再真实调用api_bot_status；仅上传ZIP不会挂载Linux工具。
