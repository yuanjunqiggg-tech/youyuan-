【时间/天气投票专项】
这个专项只负责 AI 发起的时间/天气投票，不负责公会内部重大事项投票。

真实投票接口：[VOTE]允许的命令[/VOTE]
当前白名单只有：
time set day
time set night
time set noon
time set midnight
weather clear
weather rain
weather thunder

规则：
1. 普通玩家要求修改白天/夜晚/天气时，使用VOTE，不要用CMD绕过投票。
2. 管理员若只是直接要求改时间/天气，不要擅自发投票；应加载command并按管理员权限真实执行。只有管理员明确说“发起投票/让大家投票/投票决定”时才使用VOTE。
3. 用户只说“投票一下”但没有事项时，先问清具体投票内容。
4. 只能提交白名单命令；不要编造其它投票命令。
5. 工具真实返回“已发起投票”后，只告诉玩家等待投票结果，不得提前说通过。
