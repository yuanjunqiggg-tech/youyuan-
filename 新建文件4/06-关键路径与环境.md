## 高频坑（血泪， BOOT.md 有完整版）

1. `cmd/server` 永远编译不过（结构性），忽略它。
2. Go module 名是 **bot-apk**，import 配置包写 `"bot-apk/config"`。
3. wrangler deploy 中断（22/34 资产处）是常态：先在线核查基线再重试，差量上传秒完成。
4. 往 47.102.156.125 传大文件：**限速 ≤200KB/s 或走服务器侧拉取**（今晚 51MB 直传挤死带宽，机器人全掉线）。
5. Windows→Linux 传 .sh 必须 LF（CRLF 会 `syntax error near done`）。
6. SSH host key pin 是 sha256(公钥 blob) 的 hex；paramiko `get_fingerprint()` 是 MD5，别混。
7. Linux 服务端口 19429；updates 域裸 urllib 403，必须带浏览器 UA。
8. PS 5.1 脚本要 UTF-8 BOM；后台长任务 2 分钟超时会杀，gradle 构建要分步或显式 timeout。
9. `upstream/frontend/` 与 `cloudflare/public/` 是两份独立前端，改完必须 cp 同步。
10. 部署脚本别用 `| tail`（缓冲看不到进度）。
