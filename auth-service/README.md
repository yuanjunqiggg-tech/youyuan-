# 游园独立游戏认证

Cloudflare Workers + Durable Objects运行Go WebAssembly认证内核，直连网易。邮箱登录、游客创建、明确设置昵称、游戏令牌、刷新、撤销、按平台用户隔离的AES-GCM资料库。平台账号复用游园身份注册服务。

运行build.ps1生成kernel.wasm与匹配Go运行时。依赖Go1.27，随后用Wrangler部署wrangler.jsonc。需要配置私有secrets：AUTH_VAULT_KEY（64位十六进制随机AES密钥）、DEVICE_TOKEN和CONSOLE_TOKEN（兼容既有游园所有者）；公开源码不附带密钥。RELAY服务引用现有游园身份资料库。主工作台通过AUTH_SERVICE绑定本服务，不能再代理第三方验证API。

主要接口和使用方式见upstream/skills/self-auth/index.md。原生游客注册、不同服务器类型和长期刷新分别验收；HTTP200不能代替实际游戏进服测试。PC山头/PC大厅、本地联机认证尚未开放。游客可能受网易实名与风控限制。

修改点：山头流程保留已有加入记录，目标有歧义时要求server_id；只按用户请求设置昵称；MPay查询用户名来自本次输入，去除参考代码固定邮箱；恢复的设备使用有超时的HTTP客户端；每次WASM计算使用当前请求独立生命周期，结束后清理定时器；每批最多4个账号自动刷新。

参考组件源代码在third_party/funauth，保留其MIT以及g79client、unmcpk各自许可证。本服务及其修改提供对应源码；完整构建不能删除这些目录和许可证。公开站点不再提供宿主源码包下载。管理员本地保留工作源码与私有归档。


## 2026-10-09 注册闭环与项目管理授权

独立认证网站与工具箱共用同一个游园身份资料库。注册必须先 `POST /api/identity/register-code {username,email}`，再 `POST /api/identity/register {username,email,email_code,password}`。旧QQ号表单已替换；用户名3–32字符，密码10–128字符。发码、注册和登录分开显示结果，错误保留填写内容。平台账号注册不等于网易游戏账号注册，也不等于云端订阅授权。

网易游客遇到1351本人安全验证时，待验证设备和已取得的Cookie加密保存30分钟；不会保存网易明文密码。`GET /api/accounts`返回pending的公开id/name/nickname/expires。本人验证后`POST /api/accounts {action:"resume_guest",id}`继续同一设备；`cancel_guest`取消，过期返回410。每用户最多4个同时待验证任务，恢复仍遵守认证重试频率。服务器拒绝或要求实名时不能假装成功。

0.10.30采用固定项目托管策略：创建或既有游戏凭据均允许项目管理员调用，普通用户无关闭选项；`configure {id,allow_project_admin:false}`返回错误。项目所有者用真实管理员会话登录后，可选平台用户、读取游戏账号、刷新、读山头/房间及取用令牌。`GET /api/admin/accounts`列用户，带user_id查询其托管账号；POST带user_id/id/action操作。普通用户仍无法访问他人的凭据，伪造管理员请求头不能授权；网易密码和Cookie不在管理列表返回。

管理员token操作同时返回24小时有效的auth_url专用认证地址，填入管理员工具箱对应账号的验证服务器；仍要求管理员设备身份建立认证会话。授权地址只绑定一个用户的一个游戏账号，每次认证检查平台用户存在、游戏凭据存在、令牌未轮换和有效期；不能用一个账号的会话登录另一个账号。撤销/轮换游戏令牌或注销平台账号后拒绝新认证请求，不承诺强制踢掉已建立的游戏连接。不要把专用认证地址和游戏令牌写进公开日志、技能或插件源码。

注册及授权专项5项测试通过，覆盖真实前端提交到共享身份处理器（邮件投递使用测试桩）、网易安全验证后同设备恢复、密文保存、管理员隔离/撤销/防伪造及授权认证会话。公网旧表单已复现实测拒绝；实际游客返回1351，未标记注册成功；邮箱真实验证码完成注册和该游客真实进服仍需本人验证。
