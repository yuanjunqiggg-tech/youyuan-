# 客户端与代理采集接入

当前已经能采集**工具箱自身机器人的加密前输入**，外部JSONL上报器也已通过公网验证。它不会自动接管玩家的游戏连接；真实玩家必须使用实际接入了输入监听的客户端/代理，事件生产方再调用上报器。

在插件中调用：

```lua
local me = bot.self()
local source = observerBridge.create({
    name="自身输入", source="player_input",
    server="当前实际服务器编号", player_id=me.name
})
observerBridge.attachSelf(source.id, source.token)
-- 可选主动输入；排队不是服务器已执行
bot.swingAir()
-- 稍后读取，用返回cursor翻页；不要每轮读取全部历史
local page = observerBridge.events(0, 64)
local status = observerBridge.inputStatus()
-- 结束时停止并撤销
observerBridge.detachSelf()
observerBridge.revoke(source.id)
```

source.token只返回一次。放入玩家自己的私有配置目录，不放进公开插件ZIP。外部上报配置结构如下（占位符必须替换；平台身份与采集来源密钥是两份不同凭据）：

```json
{
  "url": "https://toolbox.youyuanqi.dpdns.org/api/youyuan/observer/ingest?device=linux-server",
  "source_id": "create返回的id",
  "token": "create返回的token",
  "sequence": 0,
  "headers": {"Authorization": "Bearer 当前被允许操作该设备的工具箱会话令牌"}
}
```

执行 `python agent.py --config 私有配置.json`，在标准输入每行提供一个实际事件对象。支持 swing_input、attack_input、position_input、health_observation、server_event。默认每行立即发送；只有显式增大batch时才等待多行。序号自动写回私有配置，Linux权限0600；Windows配置目录仍需使用用户自己的私有目录。不得让多个发送器共用同一个序号文件，分别创建独立来源。

采集桥会固定保存注册的server/player_id/source，不接受上报方冒充“服务器确认”。PlayerAuthInput.MissedSwing只能证明客户端提交了空挥输入；攻击事务也不能证明命中。真实扣血仍以UpdateAttributes或安装后的服务端引擎Provider为准。

此示例属于开发资料，不作为默认运行插件安装，也不占用用户的插件槽位。
