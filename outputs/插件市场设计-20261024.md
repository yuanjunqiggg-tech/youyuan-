# 游园插件市场与开发者中心 · 设计说明

日期：2026-10-24
范围：自建插件市场（不依赖任何第三方市场源）+ 开发者中心骨架
代码：`upstream/youyuan_market.go`、`upstream/frontend/js/youyuan_market.js`

---

## 1. 目标与边界

玩家在工具箱里直接浏览、安装插件；开发者上传自己的插件、自己定价、查看收益；平台负责审核、下架与分成。

本期做的是**能跑通的最小闭环**：草稿 → 上传版本 → 提交审核 → 管理员审核 → 上架 → 玩家安装（仅免费插件）→ 开发者查看收益口径。

本期**不做**：真实支付、退款、提现/结算打款、评分提交、截图上传、管理员审核后台页面。未做的部分在接口里返回明确错误码，不伪造成功。

## 3. 插件条目字段

| `downloads` | int64 | 下载次数（本期无下载接口，保持 0） |

| `created_at` / `updated_at` | RFC3339 | 服务端时间 |

| 字段 | 类型 | 说明 |
| --- | --- | --- |

| --- | --- | --- |

## 4. 定价与分成

### 4.1 定价

- 开发者自己填价格，单位「元」，前端换算为分提交；后端只认 `price_cents`。
- `0` = 免费；免费插件同样统计安装量。
- 价格上限 `100000000` 分（100 万元），防止溢出和误填。
- 不允许负数、小数分、科学计数法。

### 4.2 分成口径（重要）

- 一切金额用 **int64 分**，不使用 float。
- 开发者实收按 70% 向下取整：
  `developer_net_cents = gross_cents * 70 / 100`
- 平台服务费 = 实付 − 开发者实收：
  `platform_fee_cents = gross_cents - developer_net_cents`
- 这样两边相加永远等于实付金额；除不尽的 1 分归平台，避免出现「平台 30% + 开发者 70% ≠ 实付」。
- 计算基准是**实际支付金额**（`gross_cents`），不是标价。未来有优惠券/折扣时，按折后实付算。
- 退款：退款成功后该笔订单不计入 `gross_cents`；若已结算，从下一期结算中扣回。本期无支付与退款，规则先固化在文档里。
- 结算周期建议：T+7 可提现，按月结；本期只提供收益汇总，不做提现。

一行示例：`500 分 → net = 500*70/100 = 350 分，fee = 150 分`。

## 5. 上传与审核流

```
draft ──提交──> pending ──通过──> approved ──下架──> offline
  ↑                │
  └──重新编辑── rejected <──驳回（必须填理由）──┘
```

规则：

1. 新建即 `draft`，只有作者能看、能改、能上传版本。
2. `submit` 要求至少 1 个版本；`draft` / `rejected` / `offline` 可提交。
3. 管理员 `approve` → `approved`，清空驳回理由，进入市场列表。
4. 管理员 `reject` 必须带 `reason`，否则 400；插件回到 `rejected`，开发者中心展示理由。
5. **已上架插件上传新版本会回到 `pending`**，需要重新审核；旧版本仍在磁盘上，但审核期间整条插件不在市场展示，避免未审核内容被安装。
6. 状态变更只允许合法迁移，非法迁移返回 409，不做静默覆盖。

## 6. 版本与兼容

- 一个插件可有多个版本；同一 `version` 字符串不可重复。
- 详情页返回全部版本，前端默认选 `latest_version`。
- 版本自带 `mc_versions` 与 `loader`；列表接口支持 `mc_version` / `loader` 过滤（会同时匹配插件声明和任一版本声明），本期前端先做展示，筛选控件后续补。
- 安装时按请求的 `version` 找文件；不传则用最新版本。
- 包体积上限 20 MB（与现有插件导入上限一致）。

## 7. 接口清单

统一前缀 `/api/market`，JSON 响应；错误统一 `{ok:false, code, error}`。

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/market/plugins` | 公开 | 列表；`q`、`category`、`mc_version`、`loader`、`sort=hot\|new\|price`、`page`、`page_size` |
| GET | `/api/market/plugins/{id}` | 公开/作者/管理员 | 详情 + 版本列表；未上架仅作者与管理员可见 |
| POST | `/api/market/plugins` | 登录 | 创建草稿 |
| POST | `/api/market/plugins/{id}/edit` | 作者 | 改基础信息；仅草稿/已驳回/已下架可改 |
| POST | `/api/market/plugins/{id}/versions` | 作者 | 上传版本；multipart `file` 或 JSON `content_base64` |
| POST | `/api/market/plugins/{id}/submit` | 作者 | 提交审核 |
| POST | `/api/market/plugins/{id}/review` | 管理员 | `{action:"approve"\|"reject", reason}` |
| GET | `/api/market/mine` | 登录 | 我发布的插件 + 收益汇总 |
| POST | `/api/market/plugins/{id}/install` | 公开 | 安装免费插件；付费返回 402 `payment_not_connected` |

错误码：`login_required`(401)、`forbidden`(403)、`not_found`(404)、`invalid_request`(400)、`conflict`(409)、`too_large`(413)、`unsupported_file`(415)、`payment_not_connected`(402)、`install_failed`(500)。

### 落盘

```
dataDir/market/
├── plugins.json           # 插件与版本元数据
├── orders.json            # 订单流水（本期为空）
└── files/<pluginID>/<随机名>.bin
```

写入使用「同目录临时文件 + rename」原子替换，权限 0600；读取失败直接报错，不用空数据覆盖损坏文件。

## 8. 安全边界

- **不执行上传内容**：只落盘、算 SHA-256、展示元数据；安装时才交给现有 `ImportPackage` 解析 ZIP。
- 扩展名白名单：`.zip`、`.lua`、`.py`、`.js`；其它一律 415。
- 大小上限 20 MB；base64 解码后再校验一次，防「声明小、实际大」。
- 文件名只取 basename，拒绝 `/`、`\`、`..`、控制字符；磁盘文件名随机生成。
- 包内容不做信任：`ImportPackage` 已有 zip-slip、条目数、解压总量限制，市场层不绕过。
- 富文本按纯文本渲染（`textContent`），不 `innerHTML` 用户内容，避免 XSS。
- 截图 URL 只允许 http/https 或站内绝对路径，拒绝 `javascript:`、`data:`。
- 写接口必须登录；作者校验在服务端做，不信任前端传的 `author_id`。
- 金额只收整数分，服务端再次校验范围，避免负数或溢出。

## 11. 验收口径

1. 空数据时列表返回空数组，前端显示空态，不出现演示插件。
2. 开发者 A 无法修改/上传/提交开发者 B 的插件。
3. 非管理员调用 review 返回 403；reject 不带 reason 返回 400。
4. 上传 `.exe` 返回 415；超过 20 MB 返回 413；成功响应里有 SHA-256。
5. 免费插件安装后 `installs +1`，本机插件目录出现对应插件。
6. 付费插件安装返回 402 且 `installs` 不变。
7. `gross=500` 时 `net=350`、`fee=150`；`gross=1` 时 `net=0`、`fee=1`，两者之和恒等于 gross。
8. 390px 视口无横向溢出，付费按钮禁用且文案为「支付未接入」。
