# MCORT 账号页 UI 修复报告

范围：`frontend/js/youyuan_accounts.js`、`frontend/js/youyuan_skin_viewer.js`、
`frontend/css/youyuan_accounts.css`、`frontend/js/youyuan_game_auth.js`，
以及授权的 `auth-service/public/console.js` 两处。未部署、未重启服务、未跑 Go 测试。

## 已完成

1. **账号标识默认隐藏**：卡片详情 / 托管详情里的「账号标识」不再渲染 `account.id`，改为固定掩码
   「已隐藏 · 点查看显示」+「查看」按钮；明文只存在 JS 内存，点击后才写进 DOM，**60 秒自动回落**。
   所有「名字为空时拿 id 兜底」的可见文案（头像首字、列表行、详情标题、身份牌、复制文案）全部改成
   「未命名账号 / ?」，不再泄漏 id。
2. **令牌行统一掩码**：本地账号令牌行、托管账号令牌行原来分别显示「已保存 · 默认打码」和后端
   `token_masked`（令牌前缀），现在统一为固定掩码；查看后同样 60 秒自动回落，托管详情的按钮文字同步
   从「隐藏」恢复「显示」。
3. **走动 / 纤细 / 正视角偏移修复**：控制条从「整个形象区之后的兄弟节点」移进形象列，变成
   `模型 + 控制条` 的 flex 竖列（`align-items:center` / `justify-content:center`，无绝对定位）。
   ≤600px 形象区改单列堆叠：模型居中在上、按钮紧跟其下、身份与操作在下方，360px 下按钮不再被右栏
   推到底部。6 个宽度实测均无横向溢出、无裁切（数据见下）。
4. **认证站两处已改**：`/health` 改为带当前会话/设备令牌；删除「官方头像选择接口正在核实…」过期文案。

## 二、六种宽度量测（按钮位置 / 是否溢出）

量测页：`outputs/ui-fixes/harness.html` + `harness-content.html`；结构与断点直接引用线上同一份
`youyuan_accounts.css`，iframe 宽度即媒体查询宽度。视口高度 1100，坐标相对 iframe 视口。

| 宽度 | 模型底边 | 按钮条 top–bottom | 条高 | 三按钮整体 left–right | 模型→按钮间距 | 横向溢出 | 右侧裁切 |
|---|---|---|---|---|---|---|---|
| 320 | 256 | 266–298 | 32 | 82–238（一行居中） | 10px | 否 | 否 |
| 360 | 256 | 266–298 | 32 | 102–258（一行居中） | 10px | 否 | 否 |
| 390 | 256 | 266–298 | 32 | 117–273（一行居中） | 10px | 否 | 否 |
| 430 | 256 | 266–298 | 32 | 137–293（一行居中） | 10px | 否 | 否 |
| 768 | 294 | 304–395 | 91 | 24–118（两行居中） | 10px | 否 | 否 |
| 1440 | 292 | 302–393 | 91 | 186–280（两行居中） | 10px | 否 | 否 |

- 6 个宽度 `documentElement.scrollWidth === innerWidth`，均无横向溢出。
- 768/1440 保持两列布局，112px 形象列里三个按钮自动换两行、居中；320–430 单列后三个按钮一行排下。
- 所有宽度按钮条都在视口内（top≥0、bottom≤1100），无被 `overflow:hidden` 的卡片裁切。
- 修复前控制条是形象区的**兄弟节点**，排在整块 hero 之后；360px 下右栏的操作按钮与令牌行把 hero
  撑高，控制条就被排到模型下方很远的位置，视觉上与模型脱节。现在它属于形象列内部，模型多高都不会
  被右栏影响。

## 五、已知风险

- 账号标识明文仅在用户点「查看」时出现 60 秒；60 秒计时用页面内 `setTimeout`，标签页被系统冻结时
  计时可能延后，但页面不可见，恢复后最多再显示到下一次计时触发。
- `yyAcctIdentValues` 是页面内存映射，开发者工具可读；这是浏览器内展示的固有边界，若要更强隔离需
  后端下发一次性句柄，属于接口改动。
