# 账号页电脑版排版修复 · UI 布局报告

> 需求来源：用户原话「电脑版的那个宽度以及排版 主要就是账号里面的其他东西 要么上下不对齐，要么是繁杂的 要么就是不工整的」。
> 文件所有权：只改 `upstream/frontend/css/youyuan_accounts.css` 与 `upstream/frontend/css/youyuan_account_pool.css`，未改任何 .js。

## 一、DOM 结构结论（只读分析，来自 youyuan_accounts.js）

账号页 `#tab-accounts` 自上而下：

1. `.yy-account-toolbar.yy-cred-toolbar`：添加账号 / 刷新账号 / 皮肤库 / 进入主账号（`hidden`）四按钮
2. `.yy-account-overview`：四格统计
3. `.yy-center-tabs`（三个入口） + `.yy-projects`（项目筛选）——原来这是两行同款胶囊
4. `.yy-account-toolbar`（搜索 / 每页条数 / 只看主账号）
5. `#yy-accounts-grid.yy-account-list`：每账号一个 `<details class="yy-account-card">`
   - `<summary class="yy-account-summary">`：头像 44px / 名字+身份徽章+在线点 / 服务器 / 状态 / 箭头，四列 grid
   - `.yy-account-detail`：形象区（立绘+头像+服务器/UID/连接三格）、动作、令牌、皮肤条、本地连接字段表、云端凭证
6. `#yy-account-pages.yy-pagination`：上一页 / 页码 span / 隐藏提示 / 下一页
7. `.yy-monitor`：运行记录 + 聊天记录（五个筛选项一行）

托管池是独立子页（`openSubPage` → `#sub-page`）：搜索条 + 五组分面 chips + 按玩家分组 + 行（内容+右侧状态/两个图标钮）。

## 三、验证（真实 Chrome，playwright-core）

- 环境：`C:/Program Files/Google/Chrome/Application/chrome.exe`，1440×900 与 390×844 两视口

- 关键量测（改前 → 改后）：
  - 桌面内容宽：1152 顶格 → 1120 居中（x=272，左右各 48px）
  - 列表行 grid 六行：`44px 997px 33px 12px` 等六种乱值 → `44px 868px 124px 14px` 完全一致

  - 横向滚动：桌面 1440/1440、移动 390/390，无溢出；两端均无 JS 报错
  - 移动端列表行 grid 前后一致（`36px 185px 78px 9px`），未推翻移动版
