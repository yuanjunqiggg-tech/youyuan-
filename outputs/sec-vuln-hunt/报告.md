# 游园 / MCORT 工具箱 · 红队只读审计报告

审计范围：`upstream/*.go`（Go 内核 0.10.75）、`cloudflare/worker.mjs` 及其模块、`auth-service/worker.mjs`、`upstream/frontend/js`。
方法：只读代码审计 + 2 次只读 GET 探测（未做任何写操作、未压测、未改配置、未改源码）。

术语：**玩家** = 游戏内角色；**用户/群友** = QQ 侧的人；**账号** = 登录工具箱的账号。

---

## 1. 结论摘要

1. `/api/youyuan/exports/download` 的「能力型 token」在 Worker 与 Go 两侧**都没有被校验**（Worker 只检查长度 ≥8，Go 完全不读 `token` 参数），而 Worker 对该路径**跳过全部登录校验**并把它送到共享 Linux 节点的 owner 桶 —— 任何知道 32 位十六进制导出 id 的人都能匿名下载插件备份 ZIP（源码+配置+数据）。
2. Go 内核把「没有 actor 头」当成「本机已绑定账号」，而上面这条路径恰好不带 actor 头，于是匿名请求在 Go 侧拿到的是 owner/admin 身份，`d.OwnerID != actor.ID` 的所有权校验被 Admin 直接绕过。
3. 平台账号的 `control_token` 是**永久、不可轮换、不可吊销**的登录等价凭据，并且作为「账号标识」明文显示在「游园平台账号」页；改密码/管理员重置密码只清 `session:`，清不掉它，令牌一旦被看到就再也踢不掉。

## 2. 高危清单

### H-1 「能力型下载」token 形同虚设：匿名可下载任意插件备份
- **危害**：无需登录、无需订阅，只要知道 `id`（32 位小写十六进制）就能拿到 `/var/lib/youyuan/插件导出/<id>.zip`。该 ZIP 由「完整插件备份」生成，按产品自述包含**插件源码、配置及数据**（模型 API Key 等敏感配置通常就在插件配置里）。文件下载后终端用户可离线分析、二次分发。
- **位置**：
  - `cloudflare/worker.mjs:85`（判定 `capDownload`，只看 `token.length>=8` 与 id 形状）
  - `cloudflare/worker.mjs:86`、`89`、`95`（该路径被排除出 `protectedPath` / 订阅校验 / 登录校验）
  - `cloudflare/worker.mjs:104`（`capDownload` 强制 `requestedDevice='linux-server'`，落到共享节点）
  - `upstream/youyuan_export_center.go:194-208`（下载处理器只调 `yyExportActor`，`r.URL.Query().Get("token")` **在整个仓库里没有任何一处被读取**）
  - `upstream/frontend/js/youyuan_export_center.js:4-12`（前端把 token 算成 `sha256` 前 16 位）
- **攻击路径（可直接照做）**：
  1. 拿到任意一个导出 id（来源：别人分享的「复制下载链接」、浏览器历史、截图、AI 会话/日志回显）。
  2. `GET https://toolbox.youyuanqi.dpdns.org/api/youyuan/exports/download?id=<32hex>&token=aaaaaaaa`
  3. 直接得到 `application/zip` + `X-Content-SHA256`。
  说明：`token` 传 `aaaaaaaa` 即可，长度够就行；真正的门槛只剩 id 的 128 bit 熵。
- **实测证据（只读，2 次 GET）**：
  ```
  $ curl ... '.../api/youyuan/exports/download?id=000...000&token=aaaaaaaa'
  404 text/plain; charset=utf-8        ← Go 的 http.NotFound（说明已越过 Worker 鉴权并解析出 actor）
     "404 page not found"
  $ curl ... '.../api/youyuan/exports/download?id=000...000'      # 不带 token
  401 application/json
     {"ok":false,"error":"登录状态已失效，请重新登录","code":"AUTH_REQUIRED"}
  ```
  404 是 Go `yyExportRecord` 读不到记录时的 `http.NotFound`（`youyuan_export_center.go:131,206`）；若卡在鉴权会是 403 文本。带一个任意 8 字符 token 就从 401 变 404，证明**登录校验被整段跳过、且 token 未被校验**。
- **代码片段**：
  ```js
  // cloudflare/worker.mjs:84-86
  // 插件导出能力型下载：URL 自带 token（≥8位）即免登录直通 box 侧 owner 兜底下载
  const capDownload = url.pathname === '/api/youyuan/exports/download'
    && (url.searchParams.get('token') || '').length >= 8
    && /^[a-f0-9]{32}$/i.test(url.searchParams.get('id') || '');
  const protectedPath = !capDownload && (device || url.pathname.startsWith('/api/') || ...);
  ```
  ```js
  // cloudflare/worker.mjs:95
  if (!qqCallback && !libraryDevice && !capDownload && !identity && (...) ) { 401 }
  ```
  ```go
  // upstream/youyuan_export_center.go:194-208
  a, e := yyExportActor(r, false)          // ← 这里用「无 actor 头就算本机 owner」的兜底
  if e != nil { http.Error(w, e.Error(), 403); return }
  v, e := yyExportRecord(root, r.URL.Query().Get("id"), a)   // token 参数从未参与
  ```
- **修复建议**：删掉 `capDownload` 这个免登录分支（改为先 `identityResolve`/`capabilityResolve` 再放行），并在 Go 侧真正校验 `token == sha256[0:16]` 且加限速、过期、可吊销；id 不应作为唯一凭据。

### H-2 control_token 是永久不可撤销的「账号标识」，且明文展示
- **危害**：`control_token` 被 `identityResolve(purpose='session')` 当会话接受（`cloudflare/identity.mjs:55` 的 `|| await ctx.storage.get('control:'+hash)`），而 Worker 给它的默认 scope 是 `control`（`pool-identity.mjs:6`）。谁能看到它，就等于永久拿到该账号的全部控制权限（含阅读账号池、下发游戏命令、改配置）。它没有过期时间、没有轮换接口、改密码也不会失效。
- **位置**：
  - `cloudflare/identity.mjs:143`（登录响应明文返回 `device_token` 与 `control_token`）
  - `cloudflare/identity.mjs:55`（session 解析回落到 `control:`）
  - `cloudflare/identity.mjs:38`（动作白名单里没有 rotate/revoke）
  - `cloudflare/identity.mjs:101`、`151`（重置/修改密码只删 `session:`）
  - `upstream/frontend/js/youyuan_identity.js:297`、`329`（存进 `sessionStorage['yy-user-control']` 并回显在只读文本框，标签为「自己的云端 MCP 控制密钥」）
- **攻击路径**：截图 / 屏幕共享 / 浏览器扩展 / 任一 XSS / 用户主动粘贴 → 取得 `control_token` → 之后无论对方改几次密码都能 `Authorization: Bearer <control_token>` 直接调用（`/api/identity/me` 除外）。受害者只能「注销账号」（`removeAccount` 才会连带删 `control:` 记录）。
- **修复建议**：给 control_token 加过期与轮换接口，改密/重置密码/登出时一并删除 `control:` 记录；界面上不要再暴露它，改为一次性「生成 MCP 连接」（已有的 `/mcp/link/<token>` 正确做法）。

### H-3 无 actor 头 = 本机 owner（Go 侧授权兜底被匿名路径命中）
- **危害**：Go 内核是「只监听 127.0.0.1、由中继用本机 key 回放」的信任模型（`youyuan_remote.go:601-603` 对每条中继请求强制 `Authorization: Bearer cfg.Key`）。真正的租户判定只靠 `X-YouYuan-Actor`；而 `yyPoolActorRequest` 在**两个头都为空**时直接返回「本机绑定账号」（`youyuan_pool_identity.go:50-56`）。H-1 的路径正好不带该头，于是匿名请求以 owner 身份执行，`yyExportRecord` 里的 `!actor.Admin && d.OwnerID != actor.ID` 因为 Admin=true 失效（`youyuan_export_center.go:139`）。
- **位置**：`upstream/youyuan_pool_identity.go:41-56`；`upstream/youyuan_export_center.go:46-66`、`139`；`cloudflare/worker.mjs:140`（只有 `actor` 非空才设置该头）；`cloudflare/worker.mjs:132`（`poolActor` 在无 identity 时返回 null）。
- **攻击路径**：同 H-1。若该 Linux 节点绑定的平台账号是 `legacy_owner`，则 **Admin=true → 可读所有用户在该节点上的导出**；若是普通账号，则至少是该账号全部导出。两者都不需要任何凭据。
- **修复建议**：`yyPoolActorRequest` 去掉「空头即本机账号」的兜底（本机调用改用显式 `X-YouYuan-Local-Owner` + 仅回环地址 + 独立密钥），并让所有 `/api/youyuan/*` 在缺少 actor 时默认 401。

## 3. 中低危清单

### M-1 订阅到期仍可下载导出（绕过付费墙）
- 危害：`capDownload` 被排除出 `protectedPath`，`cloudflare/worker.mjs:89` 的 `cloud_allowed` 校验不会执行。订阅过期的用户/任何拿到链接的人继续能下载。
- 位置：`cloudflare/worker.mjs:86,89,95`。修复：能力链也要查 entitlement。

### M-2 device_token / control_token 无轮换、无吊销接口
- 危害：登录响应同时下发两枚 256 bit 永久凭据（`cloudflare/identity.mjs:143`），白名单动作里没有 rotate（`:38`）。设备被卖/被借后原 token 永久有效。
- 位置：`cloudflare/identity.mjs:38,129,134,143`。修复：加 rotate 动作并在改密时轮换。

### M-3 普通 admin 可接管任意成员账号
- 危害：`role=admin`（非 legacy_owner）调用 `reset-password` 可改任意非管理员成员的密码并清空其全部会话，等于账号接管（`cloudflare/identity.mjs:94-101`）。同时 `users` 动作把这些人的邮箱/QQ 全量返回（`:95`）。
- 位置：`cloudflare/identity.mjs:92-101`，其中 `:98` 只保护「管理员目标」，`:104` 只保护 legacy_owner。
- 修复：重置密码限定项目所有者，或要求目标账号二次确认；`users` 对 admin 脱敏邮箱。

### M-4 `/api/youyuan/identity` 无 actor 校验，直接回吐 owner 控制令牌
- 危害：GET 返回 `control_token` 和登录态（`upstream/youyuan_identity.go:137`），处理器只挡 `yyAccounts.Worker`，**没有任何 actor/权限判断**。服务只监听 `127.0.0.1`（`upstream/main.go:5243`），所以是**同机任意进程/用户可读**（共享 VPS 上真正的越权面），不是公网可直取；公网侧仅靠 Worker 的 `sharedPoolAllowed` 白名单（`cloudflare/pool-identity.mjs:14` 不含该路径）挡住共享节点订阅者，白名单一旦加项或新增直连/新设备路径，就是 owner 账号整体泄漏。
- 位置：`upstream/youyuan_identity.go:112-137`；`upstream/main.go:5243`；`cloudflare/pool-identity.mjs:14`；`upstream/youyuan_account_pool.go:521`。
- 修复：该接口只允许本机回环或 `actor.Admin`。

### M-5 能力下载无速率限制、无过期、无吊销
- 危害：链接永久有效，只能靠删备份失效；`/api/` 全局限速不存在（`cloudflare/worker.mjs:179-183` 只限制 pending 队列 64）。泄漏后无法止血。
- 位置：`cloudflare/worker.mjs:85,179-183`。修复：能力 token 加 TTL + 一次性/可撤销记录 + 每 IP 限速。

### M-6 匿名流量可消耗 Durable Object 配额，拖垮整个产品
- 危害：`capDownload` 之前就分流到 `RELAY` DO（`cloudflare/worker.mjs:109`），无鉴权、无限速。攻击者持续打该路径即可把免费额度打满，全站返回 `RELAY_QUOTA_EXCEEDED`（代码自己已经预置了这个兜底，`:245`）。未实测（遵守不压测约束）。
- 修复：同 M-5，且把该路径纳入统一限速。

### M-7 QQ 官方回调私钥派生对短 secret 无下限
- 危害：Ed25519 私钥直接用配置 `secret` 作 seed，长度不足时**循环拼接**（`upstream/youyuan_qq.go:864-871`）。短/低熵 secret 可离线暴力枚举，猜中即可伪造任意 QQ 事件（含管理员指令触发）。
- 位置：`upstream/youyuan_qq.go:864-871,901-911`。
- 修复：**只加长度校验**，设置 secret 时拒绝 <32 字节的值（并要求高熵随机）；推导逻辑一个字都不要动——该「secret 周期重复到 32 字节再取前 32 字节」正是 QQ 官方机器人规范的 seed 推导方式，改成 `sha256(secret)` 会得到不同公钥，平台侧验签 100% 失败、官方回调全断。


### M-8 auth-service：`/api/phoenix/*` 未剥离客户端 `X-YouYuan-Project-Admin`
- 危害：`/api/accounts` 分支显式删除该头（`auth-service/worker.mjs:111`），但 `/api/phoenix/*` 分支只是复制请求头（`:78`）；vault 里 `admin=true` 会改变列表与待验证项返回（`auth-service/worker.mjs:218-221`）。目前只影响调用者自己的 vault（owner 头由服务端写入），属权限面扩大而非跨租户。
- 修复：在 `:78` 与 `:111` 一样删除该头。

### L-1 id 大小写校验不一致
- Worker 用 `/i`（`cloudflare/worker.mjs:85`），Go 要求全小写（`upstream/youyuan_export_center.go:39-45`）。大写 id 会先绕过 Worker 再 404，可作探测差分。修复：统一小写。

### L-2 token 放在 URL 查询串
- `upstream/frontend/js/youyuan_export_center.js:8-12` 把 token 拼进 URL，「复制下载链接」会进入剪贴板/历史/Referer/访问日志；且该 token 本身不被校验（H-1），是纯噪声却带来泄漏面。

### L-3 `isPrivateDistributionPath` 只解码一次
- `cloudflare/private-distribution.mjs:6-13` 对 `%252e%252e` 这类双重编码只解一层，过滤靠 `segments` 匹配。若 `env.ASSETS` 再解一次码，源码/`kernel.wasm` 过滤可能被绕过。**待验证**（需在预发环境试 ASSETS 行为，未对生产发包）。

### L-4 皮肤缓存目录 0755、图片 0644
- `upstream/youyuan_skin_cache.go:102,328`。同机其他系统用户可读缓存图片，非机密，仅信息暴露面。建议 0700/0600。

## 4. 已排查、未发现问题的面（避免重复劳动）

- **SSRF（皮肤代理）**：`/api/skin/proxy` 只允许 https、拒绝 URL 内凭据、主机白名单按后缀精确判断（`youyuan_skin_cache.go:66-81,196-217`），重定向每次重新校验且最多 3 跳（`:114-119`），拨号时自行解析并逐个拒绝内网/CGNAT 后直连已校验 IP（`:133-179`）——DNS rebinding 与重定向绕过都已封堵。仓库内**不存在** `/api/youyuan/fetch` 之类通用代理。
- **路径穿越**：`yyProjectPath` 拒绝绝对路径、`..`、盘符、任意层级符号链接（`youyuan_agent.go:122-144`）；导出 id 严格 32 位小写 hex（`youyuan_export_center.go:39-45`）；资料库 id 限 UUID 正则（`cloudflare/worker.mjs:216`）；`plugin-outputs` 的 `file` 参数走 `yyProjectPath`（`youyuan_plugin_outputs.go:16,157`）。
- **命令注入**：`exec.Command` 均为固定可执行文件 + argv（`youyuan_native_desktop.go:67`、`youyuan_runtime_desktop.go:84`、`youyuan_map_video.go:227`），未见 `sh -c` 字符串拼接；插件本身有代码执行能力属设计。
- **ReDoS**：唯一由用户填写的正则来自违禁词规则（`youyuan_qq_moderation.go:142,206`），只作用于规则所有者自己的群，无跨租户输入。
- **XSS（抽查）**：群成员目录、群消息、公告、导出中心、成员卡片全部走 `yyEscape`/`textContent`（`youyuan_qq_member_ui.js:48-53,176-186`、`youyuan_qq_assistant.js:426-437`、`features/announcements.js:131,170`）。667 处 `innerHTML` 未全量审完，但高风险数据面（群昵称、群名、聊天文本、玩家名）已覆盖。
- **QQ 回调鉴权**：缺签名或签名错误一律 401，`X-Bot-Appid` 不匹配 401，`op=13` 校验流程正确（`youyuan_qq.go:899-911`）。OneBot 走反向 WS，没有入站 webhook。
- **观测数据入口**：`/api/youyuan/observer/ingest` 用 `sha256(token)` 常量时间比较，且 token 必须 64 位（`youyuan_observer_bridge.go:101-135`）。
- **CORS**：除 `turnstile-config` / `pow-challenge` 外没有任何 `Access-Control-Allow-Origin`，不存在跨站带凭据读取。
- **凭据落盘权限**：`platform-identity.json` 0600、`config.json` 0600（`config/config.go:144`）、`managed-accounts.json` 0600（`youyuan_accounts.go:90`）、导出 ZIP 0600 / 目录 0700（`youyuan_export_center.go:72,93,121`）。未发现 0644 的令牌文件。
- **账号池越权**：`/api/youyuan/accounts` 强制 `a.OwnerID = actor.ID`（`youyuan_accounts.go:518`，明确拒绝客户端提供 owner），读取按 `yyPoolCanUse` 过滤（`:390-400`），明文令牌接口经 `yyPoolRequire`（`youyuan_account_pool.go:160-166,719-724`）；未发现 mass assignment。
- **租户隔离**：非 owner 的 `relay_prefix = tenant:<uid>:`（`cloudflare/identity.mjs:58`），`?device=` 无法逃出前缀（只允许 `[A-Za-z0-9_-]{1,48}`，`worker.mjs:105,108`）；assigned 用户受 `sharedPoolAllowed` 白名单限制（`worker.mjs:133-137`、`pool-identity.mjs:14-33`）。
- **`/api/library/*`**：按 `deviceId` 分 DO，删除需 POST，跨租户不可达（`worker.mjs:108,164,197-227`）。
- **mcp-link**：URL 里是 256 bit 随机 token，存储键为 sha256，列表只回 hash（`identity.mjs:89,81`）。

## 5. 需要人确认 / 我无法判断

1. **Linux 节点绑定的平台账号是不是 `legacy_owner`**：这决定 H-1 是「读该账号全部导出」还是「读全站所有用户的导出」。看 `platform-identity.json` 的 `user.legacy_owner` 即可。
2. **线上 Go 二进制是否与本仓库 `upstream/` 一致**：我用「带任意 token 返回 Go 的 404、不带 token 返回 Worker 的 401」推断线上没有 token 校验，但无法直接看二进制。若线上版本另有校验，H-1 降级为「token 可预测（sha256 前 16 位）+ 分享链接永久有效」。
3. **token 的设计意图**：前端注释写「导出自带 SHA256 前 16 位」，但两侧都没实现校验，疑似「写了生成端、漏了校验端」。请确认是否还有未提交的校验代码。
4. **Cloudflare 是否对 `/api/*` 配了缓存规则**：若有 Cache Everything，H-1 的响应可能被边缘缓存，泄漏面进一步扩大（响应头只有 Go 侧 `private, no-store`，`youyuan_export_center.go:217`）。
5. **导出 id 的实际暴露面**：是否出现在 AI 会话记录、操作日志、前端埋点、错误上报里（这决定 H-1 的利用难度）。
6. **`%252e` 双编码**是否能绕过私有分发过滤（L-3）：需要在预发环境确认 ASSETS 的解码行为，我没有对生产做这类探测。
