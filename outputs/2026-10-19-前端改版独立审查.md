# 前端改版独立审查与修复

范围：`youyuan_navigation.js/css`、`youyuan_terminal.js/css`、`youyuan_agent_studio.js/css`、`youyuan_workspace.js`。本轮为源码和 Node 行为审查，不控制浏览器，不改变业务插件或游戏状态。

已修复的确认问题：

1. **切文件时可能丢失刚输入的内容。** 下一文件 GET 在途期间，旧编辑器仍可输入；旧实现会直接销毁编辑器。现在读回后先保存旧文件，保存失败或保存期间继续输入则保留原编辑器与草稿，只有确认保存且当前请求仍有效才替换。
2. **切工作区会清除未自动保存的编辑。** 新工作区提交前保存旧工作区；GET 期间旧文件又有编辑时，再保存一次。未成功便停止切换，不先清掉 dirty 状态。工作区回复还校验完整账号/登录 scope。
3. **旧账号草稿及保存迟到回复缺少所有权。** 每个文本编辑器绑定打开时的完整 `yyReadScope()`；账号或登录 session 改变后拒绝把旧草稿写到新 scope。保存回执校验编辑器对象、工作区 epoch、路径和 scope；页面销毁后不会访问空编辑器或重画另一页。请求失败返回 false，保留草稿，不让切文件 Promise 因网络异常未处理而卡住。
4. **不等待模型服务后，同工作区模型列表可能被迟到请求覆盖。** 模型读取增加请求序号、工作区 epoch、select DOM 身份与完整 scope 校验；明确读取失败保留原模型列表。
5. **运行预算弹窗可能跨账号或关闭后复活。** GET 回执、POST 前与回执均核工作区 epoch 和完整 scope；旧弹窗不能写入新账号同 ID 工作区，保存按钮还拒绝在途重复提交。
6. **终端历史覆盖未提交草稿。** ↑ 浏览前记住当前草稿，↓ 回到最新恢复草稿；Alt + 箭头保留原生行为。
7. **文件侧栏每 2 秒轮询重建按钮。** 相同路径顺序时复用按钮，仅更新激活状态与标题；保留键盘焦点和侧栏位置。

此次实际修改仅 `youyuan_workspace.js`、`youyuan_terminal.js`、`youyuan_agent_studio.js`，没有为审查扩大 UI 功能或调整导航/CSS。先将确认问题位置告知 root，再按授权修复。
