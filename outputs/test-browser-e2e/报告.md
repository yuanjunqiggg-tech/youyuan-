## 一、结论先行

| 判定 | 结果 |
|---|---|
| 乱跳 / 乱刷新 | **未发现**。20 个页面各连续采样 15s（49 次/页），`document.body.scrollHeight` 与 `scrollY` 变化次数**全部为 0**；主框架导航 0 次、SPA 无整页重载 |
| 打开连接界面是否刷新一次 | **没有刷新，也没有白屏**。点击「连接与设置」→ 首屏 139ms、653ms 后稳定（桌面）／57ms 首屏、移动端 1190 字符稳定 |
| 唯一白屏 | 桌面进「群服互通」有约 **1.0s 空白**（连续 10 帧 `innerText<200`），之后一次性渲染到 6140 字符 |

| 唯一接口缺陷 | 皮肤头像接口 **401**：`/api/skin/online-head?player=*`、`/api/skin/online-texture?player=*` |
| 视觉溢出 | 桌面 0 处；移动端 2 处（插件中心筛选按钮、终端快捷命令条） |

## 九、建议优先级

1. **修复皮肤接口 401**（`/api/skin/online-head|online-texture|proxy`）：每张账号卡、每个在线玩家都各打 1 次失败请求，既污染控制台也浪费额度。
2. **移动端游戏账号卡片展开失效**：`details[open]` 不变，用户看不到账号详情。
3. **移动端终端快捷命令溢出**（`clear` 超出 114px 完全不可见）与插件中心筛选按钮溢出 30px。
4. **群服互通首屏约 1s 白屏**：可先渲染骨架屏再填数据。
5. **认证站 `data:,` CSP 报错**（Turnstile 相关）与 `%c%d … NaN` 调试残留；`/console`、`/dashboard` 深链返回 404 JSON，应重定向到登录页。
