# 账号头像占位图标设计参考

- 日期：2026-10-23
- 设计人：Agent-B（游园项目调研子 Agent）
- 问题：认证站账号页的头像占位图标现状是「一个圆圈套一个正方形、里面还有个实心包围柱」（用户原话：「一看就是 AI 做的，能不能有创意点，去借鉴各种 GitHub 仓库？」）。本文件给出借鉴来源、设计思路、3 个候选方案与推荐款。

---

## 一、借鉴了哪些 GitHub 项目，借的是什么

| 来源 | 借用的手法 |
| --- | --- |
| [mineatar-io/skin-render](https://github.com/mineatar-io/skin-render)（51★） | `RenderHead` 的**等距三面构图**：一个 MC 头同时露出顶面/正面/侧面，用面的明暗差表达体积，而不是画正脸剪影 |
| [NickAcPT/nmsr-rs](https://github.com/NickAcPT/nmsr-rs)（116★，mc-heads.net 同源渲染器） | 六边形头部轮廓的**边光/暗侧分布**：亮面在右前、暗面在左，所有第三方渲染器都遵循这个光位，照抄即可获得"专业渲染感" |
| Mineatar `RenderFace` / mc-heads.net 的 2D 头像 | 8×8 网格的**五官布局**：双眼各 2×2 像素位于第 4-5 列、第 4-5 行，嘴 2×1 居中——这是 Steve 皮肤的经典比例 |
| nmsr-rs 的材质分层 | **同色系多档透明度**做体积分层（顶面最亮/正面中/侧面暗），单色图标不靠第二种颜色也能有立体感 |

反模式（现状图标的问题，全部规避）：
- 圆+方+实心柱：三个无关联的几何形硬凑，没有 MC 语言；
- 纯剪影：没有五官就没有"这是玩家头像"的语义；
- 多颜色：占位图标必须跟随主题色，不能用固定配色。

## 二、设计思路（三个候选共用）

1. **语义正确**：占位 = "一个还没有皮肤/头像的玩家头"，所以必须是 MC 头，不是圆不是人像剪影。
2. **currentColor 单色体系**：全部 `fill="currentColor"`，只靠三档 `opacity`（0.38 / 0.68 / 0.95）区分顶面、正面、暗面——深浅主题自动适配，无需第二套图。
3. **evenodd 镂空五官**：眼睛和嘴用 `fill-rule="evenodd"` 从面部路径里"挖"出来，透出背景色。小尺寸下五官依然可读，且任何背景下都不会糊。
4. **单路径优先、总体积 <1KB**：三个候选分别 762B / 554B / 684B，全部远小于 2KB 上限，可内联进 HTML 也可做独立 SVG 文件。
5. **可访问性**：`aria-hidden="true"`，装饰性图标不进读屏流程；语义由按钮/alt 文本承担。

## 三、候选方案

## 四、推荐：候选 A

理由：

1. **一眼是 MC 头，且是"渲染过的"MC 头**。三面体积语言直接借自 skin-render/nmsr-rs 的专业渲染结构，和工具里已有的皮肤立体预览（`skin_preview`）视觉同族，放在一起不违和。
2. **双主题零成本**。currentColor + 三档 opacity，深色背景（#172B39 一侧）和浅色背景（#F7F8F6 一侧）下全部验证通过，不需要 `prefers-color-scheme` 两套资源。
3. **小尺寸不崩**。32px 下双眼+嘴仍可辨，40px 以上完全舒适（见下）。B 在 24px 以下还行但 32px 时头发边界开始糊；C 的肩在 40px 以下失去形状。
4. **五官用 evenodd 挖空而不是画深色块**：背景换成任何颜色（包括彩色头像框后面）都不会出现"脏底”。
5. 体积 762B，内联无负担。

接入建议（给改代码的 Agent）：
- 直接复用落盘的 `outputs/assets/avatar-placeholder.svg`；如需内联，原样贴入 HTML 即可，无外部依赖、无 JS。
- 图标本身不携带语义，记得在按钮/容器上保留文字说明（如「暂无头像」），读屏用户靠文本。
- 显示尺寸建议 ≥32px，列表头像格 40px 最佳；小于 28px 的场景建议换候选 B（更简单的形态在小尺寸下损失更小）。

## 五、验证记录（设计闭环）

- 方法：SVG → 纯 Python 光栅化（扫描线 evenodd + src-over alpha 合成）→ PNG，在浅色/深色两种背景下目检；参考图（Mineatar、mc-heads.net 实际渲染输出）同步下载比对。
- 已通过的检查：
  - 候选 A/B/C × 浅色/深色主题，96px：三面/单面/头肩的明度分层均正确呈现，无 opacity 渲染错误（修掉了一个"背景 alpha 初始化为 0 导致所有透明度变实色"的光栅化 bug 后重新验证）。
  - 候选 A 在 32px / 40px：五官可读性达标（A 为此从 1px 眼宽改为 2px 眼宽，嘴下移一行对齐 Steve 布局）。
  - 候选 A 脸部朝向：与参考渲染一致（脸朝右前、暗侧在左）。
- 过程产物（临时目录，仅供复核，非交付物）：`%TEMP%/mcdesign/` 下的 `final_A/B/C.svg` 与各主题 PNG。
