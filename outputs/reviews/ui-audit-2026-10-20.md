## 五、设计语言一致性总结

**结论：这产品有一套"想成为体系"的设计语言，但没有落地成系统；实际是 3 套语言叠在一栋楼里。**

1. **两套调色板互相覆盖。** `css/base.css:6` 定义暖黄棕（`#d48a0e` / `#794f27`），`css/youyuan_design.css:2` 用同优先级 `:root` 定义青绿（`#087f79` / `#233338`），因为后者后加载而全胜——也就是说 `base.css` 那一整套 token 是死的。这解释了为什么 `--phx-bg-primary` 这种"看起来该有"的变量实际不存在（B1 就是这么炸的）。
2. **三套组件语法。**
   - A 套（旧）：`btn / btn-s / card / tsk-act`，出现在插件页、群服互通、资料库、登录门；
   - B 套（新）：`yy-primary / yy-secondary / yy-card / yy-heading`，出现在首页、账号页、观测页；
   - C 套（0.10.75 新工作室）：`yps-* / yy-studio-* / fp-*`，自带 `--yps-*` 私有变量与独立圆角（11px）、独立字号（10/11px）。
   同一个"主按钮"在三个套里分别是 `.btn`（40px 高、13px 字）、`.yy-primary`（36px、12px）、`.yps-button`（35px、12px）。
3. **"自己发明的第二套"具体位置**（可直接对照改）：
   - `css/youyuan_plugin_studio.css:8` `.yps-toolbar` —— 另起一套 38px 高输入框、7px 圆角、`--yps-*` 变量，与 `css/youyuan_design.css:23` 的 40px / 8px / `--phx-*` 并列；
   - `css/youyuan_studio.css:2` `.yy-studio .card{border-radius:16px!important}` —— 用 `!important` 强行改掉全局卡片 12px；
   - `css/youyuan_terminal.css:3 / :14 / :18` —— 同一个 `#tab-terminal .yy-terminal-workbench` 被定义**三次**，后一次覆盖前一次，是设计反复推翻的化石层；
   - `css/youyuan_usability.css:3-5` —— 又一套 `ocean/sakura/amethyst` 主题，只覆盖部分 token。
4. **命名没有单一事实源。** 一个屏幕四个名字（S1）、一个模块两个名字（更多工具/其他）、一个动作三种叫法（停用 / 关闭 / 停止）。
5. **唯一的正面项**：终端页是唯一"从骨架到文案都自洽"的屏幕（页头 kicker + 单栏控制台 + 明确的"Enter 发送 / Shift+Enter 换行"提示 + 失败时"不会自动重发"），建议以它为基线反推组件规范。

## 六、上架前必须修的最小集合（按性价比排序）

1. **修 `api.js` 的非 JSON 兜底**（B3）——一处改动，消灭全站 6 个屏的裸异常，收益最大。
2. **修深色模式两个根因**：`--phx-bg-primary` 未定义（B1）+ 主按钮白字（B2）——两行 CSS，救活整个深色模式。
3. **给插件市场加失败态**（B4）——目前是纯白屏，最容易被当成"App 坏了"。
4. **`undefined` 与 `"—"` 兜底**（B5 / G1）——把所有 `a||b` 模板补末位文案，一次清干净。
5. **观测页开关改用 `yySwitch()`**（B6）+ **全局抓包入口先出骨架**（B7）——观测是核心卖点，现在入口点不动。
6. **统一屏幕命名**（S1）+ **子页同步面包屑与高亮**（S2）——纯文案/一行状态同步，直接提升"成熟度"观感。
7. **768 断点合并单列**（S3）+ **账号页标题不折行**（B8）——两个 CSS 改动，解决最刺眼的布局崩。
8. **字号与对比度两档收敛**（S5 / S6）——`--phx-text-secondary` 加深、10px 只留给徽标，全站一次性变"清楚"。
9. **技术术语清理**（S10）——路径、`main`、`member_openid`、包名清单、Lua 代码这 5 类，改成中文业务词或收进"高级"。
10. **移动端 44px 触控区**（S12）——一条全局规则 + 顶栏按钮放大，解决误触。

> 未纳入最小集合但必须在 1.0 前处理：S7/S8/S9（圆角、按钮、开关三套并一套）、S11（危险操作确认）、S15（无效主题项）。
