## 二、断链定位（前端 → 接口 → 后端 → 网易）

链路逐段实测，断在**第 2 段和第 3 段**，共三处：

| # | 位置 | 事实 |
| --- | --- | --- |
| ① 主要断点 | `frontend/js/youyuan_accounts.js:1856` | `if (!row || String(row.skin_item_id \|\| "") !== key) return "";` —— 组件码 ≠ 账号**当前穿着**时**直接返回空串，一个网络请求都不发**。皮肤库有 6 款内置 + 用户自贴，最多 1 款能同时满足，其余卡片永远只有三位数字方块。这就是「组件没正常加载」。 |
| ② 取图地址维度错 | `frontend/js/youyuan_accounts.js:1843-1848` | 即使过了守卫，地址也只拼 `/api/skin/online-texture?player=<名字>`，维度是**玩家名**，与组件码无关。 |
| ③ 后端缺路由 | `youyuan_catalog.go` 原 skin 段 | 原有 `/api/skin/*` 只有 `account-head`、`account-texture`、`build`、`head`、`online-*`、`preview`、`voxel`，**没有任何以 item_id 为入参的取图路由**。 |
| ④ 名字对不上必 miss | `youyuan_skin_disk_cache.go:96`（`sha1(lower(trim(name)))`）、`:54` 目录 `插件数据文件/皮肤缓存` | 缓存键是名字；昵称 ≠ 玩家名时必然 miss。 |
| ⑤ 排除项 | `main.go:3513` `handleSkinPreview` 返回 `blockCount/width/height/length` | 确认 `/api/skin/preview` 是**雕像方块数计算器**，只吃本地 `path`，不产图片——与主控判断一致，不是预览图源。 |
| ⑥ 可用但维度不对 | `main.go:3957` `handleSkinOnlineTexture` | 先 `playerInfoMgr` 再磁盘，**只认游戏内玩家名**；本机无运行实例，未复测其 200/404，结论依据代码 + 主控实测。 |

结论：不是 CSS 问题，不是抽屉打不开，是**组件码这个维度在后端根本不存在**。

## 三、组件码 → 纹理：实现与验证

**新路由**（全部走 `mux.HandleFunc`，注册点在 `youyuan_skin_cache.go:414` 的 `yySkinItemRoutes`，由 `youyuan_qq.go:113` 的生产调用链进入）：
- `GET /api/skin/item-texture?item_id=<组件码>[&id=<本地账号>|&cred=<凭据ID>]` → PNG；失败回 JSON `{ok:false,item_id,error}` 带人话原因
- `GET|POST /api/skin/item-library` → 群友分享的组件码列表（`插件数据文件/皮肤组件库.json`，上限 200 条，纯数字校验）

**解析顺序**（`youyuan_skin_item.go:446` `yySkinItemLookup`）：本地 `插件数据文件/皮肤组件缓存/<组件码>.png` → 账号正穿着它就复用账号纹理（不打网易）→ `皮肤组件凭据.json` → 认证服务 `action:"skin_info"` 回传的 g79 `client` 快照（`UserID`/`UserToken`/`ReleaseJSON.ApiGatewayUrl`，**只读，不改账号皮肤**）→ 网易 `get-download-info` → `res_url` → 下载 → zip 里挑 `skin.png` 或裸 PNG → `yySkinTexturePNG` 尺寸闸 → 落盘。失败 3 分钟内负缓存，不反复打远端；账号列表 30 秒缓存，避免开一次抽屉打 6 次认证服务。

**凭据设计（任务要求项）**：`插件数据文件/皮肤组件凭据.json` `{"user_id":"…","user_token":"…","api_gateway":"https://…"}`。有认证账号时优先用账号实时登录态（含会话过期自动 `refresh` 重试一次），配置项是没有账号/账号掉线时的兜底——两种都没有就明确告诉用户缺什么，绝不拿别的皮肤图冒充。

**前端**（`frontend/js/youyuan_skin_library.js`）：以同名全局覆盖接管 `yySkinLibraryFetchTexture`（任意组件码都请求 `item-texture`，失败才退回老链路）、`yySkinLibrarySyncReal`（打开抽屉把**每张**卡片都补图，并发 3）、`yySkinLibraryEntries`（并入服务端共享列表）、`yySkinLibraryRender`（卡片标 `内置/我的/群友 · 已生效/暂无图`，失败原因进 title 与预览标签）、`yySkinLibraryOpen`（注入「把组件码分享给大家」区并修正说明文案）。样式追加在 `youyuan_skin_library.css`（`.yy-skin-share` 等）。
