## 1. 群服互通的定位

你说了「这种东西不要默认就有，也要给他们一个配置选项，我们这个其实更像是一个插件了」。

- **A（建议）** 核心只有「连接 + 收发消息」，其余（帮助菜单、点赞、动态、AI 接话、转发、管理命令）全部是**可单独开关的插件模块**，默认关。
- B 核心多保留「聊天转发 + 绑定」，其余插件化。
- C 全部功能默认开，只给一个总开关。
- D 完全插件化，连「连接」也由插件提供。

---

## 2. AI 接话的触发方式

你说了：`召唤AI 改成 .AI 就限定了，它就不能自由回消息`；又要求「隔一段时间自己看聊天记录，挑想回的」。

- **A（建议）** 两种都要：`@/。AI` 立即回 + 后台每隔 N 秒读一次聊天记录，自己挑要不要回（N 可改，默认 60 秒）。
- B 只要「定时自己看、自己挑」，不要 `。AI` 召唤。
- C 只要 `。AI` 召唤，不要主动接话。
- D 两种都要，但主动接话只在被 @ 过的群里生效。

---

## 3. 群聊消息转发到游戏

你问了：`什么特定触发词，或者它能不能自动触发、自动转发，开启了之后某一时间自动转发`。

- **A（建议）** 三种模式都做，用户选：①固定触发词 ②自动全部转发 ③定时批量转发（如每 5 分钟把这段时间的聊天合并发一次）。
- B 只做「固定触发词」。
- C 只做「自动全部转发」。
- D 只做「定时批量转发」。

---

## 4. 触发词/命令的权限分层

你指出：`触发词规则当中好像并没有选择是管理员还是普通成员的分层使用`。

- **A（建议）** 每条触发词/命令单独选：所有人 / 仅管理员 / 仅超级管理员；默认「所有人」只给查询类。
- B 按分组统一设：查询类所有人、执行类管理员、危险类超管。
- C 只分「成员 / 管理员」两层。
- D 不分层，全部靠危险指令二次确认。

---

## 5. 给 AI 的工具范围

你要求：`把那些工具给 AI，你就给了几个`、`以后玩家想添加到四五十个，就是要把这个权限放开`。

- **A（建议）** 全量工具（40+）都可勾选给 AI；默认只勾「只读查询」，写操作/危险操作勾选后仍需群内二次确认。
- B 全量可勾选，勾了就直连执行，不再二次确认。
- C 只开放只读查询，写操作一律不给 AI。
- D 由插件自己声明暴露哪些工具，主程序不限制。

---

## 6. MCP 工具的接入方式

你问了：`真正启动 MCP 工具，你这个是广泛性的还是专一性的？广泛性所有玩家都能用，专一性绑定自己本机的 MCP`。

- **A（建议）** 两者都支持，用户选：①用工具箱内置/公共 MCP ②填自己的本机 MCP 地址（内网穿透/公网都行）。
- B 只支持内置公共 MCP。
- C 只支持用户自填 MCP。
- D 按账号隔离：每个托管账号可以绑不同 MCP。

---

## 7. AI 模型配置放哪

你要求：`群服互通里面的 AI 模型配置全部去掉，改成生图里面`、`模型配置搞一个统一的，语言/画图/语音`。

- **A（建议）** 统一「模型中心」：语言模型、画图模型、语音模型各选一个；群服互通只引用，不再单独配置。
- B 模型中心只管语言模型，画图/语音各自配。
- C 保持现状（互通里配语言，生图里配画图）。
- D 每个功能都能覆盖全局默认。

---

## 8. 表情包发送规则

你指出：`谁告诉你只能发一张了？谁告诉你既要说话又要发表情包？如果我没说，你为什么要擅作主张？`

- **A（建议）** 默认只发文字；表情包单独命令/单独开关；一次可发多张（上限可配，默认 3 张）。
- B 默认文字 + 1 张表情，可关。
- C 表情包完全独立，AI 不能自动带。
- D 由 AI 自己决定带不带、带几张。

---

## 9. 主动搭话 / 静默窗口 / 深夜降权

你要求：`主动搭话的相关配置也应该由用户来，深夜自动降权或者别的，也是由用户来设置`、`静默窗口这些也一样`。

- **A（建议）** 用户可加多个时段规则（如 00:00–07:00 不主动说话 / 降低频率 / 只回不主动）；每条规则可开可关。
- B 只给一个「深夜不主动」开关 + 起止时间。
- C 固定内置一套时段，用户只能整体开关。
- D 不做时段，只给「主动搭话频率」一个滑杆。

---

## 10. 帮助菜单的呈现

你说：`这种东西不要默认就有`、`也要给他们一个配置选项`。

- **A（建议）** 首次 @ 机器人时发一次，之后不再自动发；`帮助`/`。帮助` 随时可看；可在配置里选「完整版 / 精简版 / 关闭」。
- B 默认完全不发，只有主动发 `帮助` 才给。
- C 默认每次都发（现状）。
- D 由插件提供帮助内容，主程序不管。
