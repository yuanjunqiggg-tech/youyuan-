## 0 结论速览

**10 条原话核对：已解决 3 / 部分 6 / 未解决 1**

**未解决：** 第 10 条——头像不能"选/上传"。后端早就收（`upstream/youyuan_account_profiles.go:65-88`，PNG/JPEG、≤512×512、≤96KB），前端把裁剪函数也写完了（`youyuan_accounts.js:770-796`），但**整个前端没有一处 `<input type=file>`，也没有预览容器**（`youyuan_accounts.js:756` 的资料页只有名称/分类/保存）。这是半截代码，不是"没做"。

**账号页最严重的 3 个排版问题**
1. **601–1023px 这一段压根没对齐**。定宽四列只在 `min-width:1024px` 生效（`youyuan_accounts.css:284`），1023 及以下是 `auto`（`:48`）。每张卡是独立 grid，状态列按各自文字长度撑开：800px 视口下"已连接"列宽 33px、"内核在线 · 游戏未连接"列宽 109px，**同行状态区左缘相差 76px**——用户说的"上下不对齐"在这一档一字未修。
2. **桌面皮肤控制条被塞进 112px 的列里，必然折行**。三个按钮需 44+44+56+12=156px，容器只有 112px（`:179`、`:181`），结果"走动 纤细"一行、"正视角"独占第二行，控制条最底一行距模型底边 196px+ 处，且宽窄不齐。
3. **移动端状态列上限 78px，最长状态串约 99px**（`:52`、`:285`）。"内核在线 · 游戏未连接"9 个汉字×10px+间隔≈99px，被砍 21px；又因为 `text-align:right`，被省略号吃掉的是前半段语义。

**认证站「今天必须修好」的那一项，我认为是：账号头像的「选择 / 上传」入口（两端一起补），不是再加页面。**
依据：① 用户第 10 条点名要"能选/上传"，这是唯一 0% 落地的功能；② 认证站侧同样没有入口，只有一句"网易未开放头像列表与更换接口"（`console.js:193`）；③ 更有力的证据是两边都留下了**弃用的头像选择器**——`console.css:233` / `index.html:309-310,454` 的 `.auth-avatar-choices` 三条样式，全站没有任何 JS 生成它；④ 这条链是纯 UI 缺口，后端已就绪，今天能闭环，性价比最高。相比之下"再加一个页签"只会让"没做好"的感觉更重。

## 2 账号页量测

### 2.1 桌面 1440（≥1024 规则）
`.yy-sidebar` 224 固定 → `.content` 32×2 → 可用 1152 → `.content-inner` 取 `max-width:1120`（两侧各余 16）。卡带 1px 边框、`padding:0 16` → **卡内 1086**。

| 量 | 数值 |
|---|---|
| 内容宽 | **1120**（页内绝对 x 272–1392） |
| 卡内宽 | **1086** |
| 四列（头像 / 名字 / 状态 / 箭头） | **44 / 868 / 124 / 14**，列间距 12 |
| 四条对齐线（相对卡内） | 头像 0–44；名字列 56–924（文字起 70）；状态列 936–1060（右缘 1060）；箭头 1072–1086 |
| 行高 / 节距 | **64**（10+44+10）/ 74（含 10px 列表间距） |
| 六行一致性 | **通过**：六行同列宽、同行高 64，头像/名字/状态右缘/箭头四条线重合 |
| 横向溢出 | **无**（全部 minmax(0,1fr)，卡片有 `min-width:0`） |
| 状态文字余量 | "内核在线 · 游戏未连接"≈118px vs 124px，**只剩 4–6px**，任何更长文案立刻省略号 |

### 2.2 移动四档（≤600 规则）
`.content` 边距 18×2、卡 `padding:0 10` → 卡内 = 视口 − 36 − 20。

| 视口 | 内容宽 | 卡内宽 | 四列（36 / 1fr / ≤78 / 9，gap 8） | 行高 | 横向溢出 |
|---|---|---|---|---|---|
| 320 | 284 | 264 | 36 / **117** / ≤78 / 9 | 62 | 无 |
| 360 | 324 | 304 | 36 / **157** / ≤78 / 9 | 62 | 无 |
| 390 | 354 | 334 | 36 / **187** / ≤78 / 9 | 62 | 无 |
| 430 | 394 | 374 | 36 / **227** / ≤78 / 9 | 62 | 无 |

- **状态被裁**：文本约 99px ＞ 78px 上限，322 四档全都砍掉约 21px（`:52`）。
- **顶部四入口零余量**：320 下 (284−24)/4 = **65px/个**，减去左右内边距 4+4、边框 2，可用文字宽 **55px**；"进入主账号"5 字 × 11px = **55px**，正好顶满 → `overflow:hidden;text-overflow:ellipsis`（`:164`）必然出现省略号。
- 皮肤控制条可见且不溢出：44+44+56+12 = 156 ＜ 264，居中；`≤600` 时隐藏"拖动旋转"提示（`:187`）。
- 按钮裁剪：无（三按钮情形 89px/个；四按钮情形见上，只出现省略号不裁边）。

### 2.3 一句话
宽度与"六行一致"这两件事做到了；**"上下不对齐"只修了 ≥1024 和 ≤600，中间 601–1023 是真空区**，而这正是平板和半屏桌面窗口最常落在的区间。
