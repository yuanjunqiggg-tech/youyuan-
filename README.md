## 交付与运行

安装 youyuan-v0.8.0.apk。运行内核、Python、Lua、C++ 和 Agent 文件工具都在 APK 内；Cloudflare 提供前端、自己的 API、中继、AI 推理与持久资料库。PC 不承担云端生产后端。

- 云端控制台：https://toolbox.youyuanqi.dpdns.org 。注册游园账号、登记 QQ 号码、设置密码并登录。原有设备也可使用私有控制密钥。
- 公网 MCP：https://toolbox.youyuanqi.dpdns.org/mcp/ ，Bearer 控制密钥。
- APK 公网连接：设置 → 公网远控，wss://toolbox.youyuanqi.dpdns.org/device/connect，填写设备密钥。界面已展示本机 MCP 密钥。
- 游戏连接：设置 → 账号/服务器。预置 Susu 和验证服务 2，也可自行配置。登录认证仍依赖用户指定的第三方 NEMC 提供方，不独立签发网易身份。
- QQ：设置 → 群服互通，支持 OneBot 与 QQ 官方，AppID/AppSecret 显式可编辑。官方回调 https://toolbox.youyuanqi.dpdns.org/qq/webhook 。真实 QQ 凭据验证结果详见验收说明。
- AI：各语言工作区 → AI 帮写 → 启用游园云端 AI。已有设备密钥即可配置自有域名的 Workers AI；也可在工作区内改用自己的兼容模型。
- Windows EXE 与 Linux x86_64 ELF 是独立执行端。桌面 Python 设置 YY_PYTHON 为实际解释器路径；当前 Android C++ ABI 不适用于桌面。

## 工作台

首页 10 个可排序的长条工具区：导入、导出、地图画、音乐、皮肤、服务器搜索、建筑文件、其他、云端资料库、命令链。飞行控制在其他。第 2 个空间统一多语言常驻插件与 Agent，模型配置在各工作区。

第 5 个空间是账号管理，支持分页。每个额外账号拥有独立 Android 进程、游戏内核、私有目录、插件、聊天记录和玩家采样。每账号可编辑 Token、服务器和保活开关，进入账号后整套界面/API 自动路由到该账号。账号列表支持搜索及 8/16/32 条分页；保存记录不占槽位，主账号外最多配置 32 个独立运行服务；同 Token 不可重复登录。一个现有账号不能变出多个可同时在线的游戏身份。

前台服务、唤醒锁、START_STICKY、父进程检查和断线重连共同帮助保活。系统强制停止、网络故障、账号互踢、服务端拒绝不保证永久在线。常驻 Python/C++ 的启用列表落盘，进程恢复后重新加载；模块全局内存不会跨进程死亡保留，业务持久状态用 host.save()。Lua/命令链按各自配置恢复。

公网中继每 20 秒发送应用层心跳，超过约 60 秒未收到回传会关闭旧连接并重连，避免仅凭底层 WebSocket 状态显示在线。设置改变或请求队列满时取消连接，仍会继续外层重连循环。

聊天表显示真实玩家、接收时间、服务器和消息，保存最近 10,000 条；人数每 15 秒采样，保留最多 24 小时，提供时间线/每小时观测均值。数据来源是内核收到的 PlayerList，并非独立的服务器总人数接口，未知/离线显示空缺。

设置增加背景图片和工作台封面相册；原图存入设备，云端以认证接口读取。JPEG/PNG 单张 8 MB、最多 20 张自定义封面。用户提供的三张原图分别用于初始封面、加载画面、悬浮窗。

## 插件与 Agent

Python CPython 3.12、C++ 原生共享库、Lua 常驻虚拟机均有真实运行入口。Python 模块启动时载入，各事件后保留状态；每实例 JNI 工作线程、有限队列 256，已有积压时最多 16 条顺序批处理，不等待凑批。C++ 每实例 C ABI 对象常驻，源码经目标 ABI 的 NDK 编译后上传 plugin.so；APK 没有内置 C++ 编译器，可连接自己的 MCP 编译器。不是任意插件安全沙箱。

各语言说明在 upstream/skills/python-runtime/index.md、cpp-runtime/index.md、command-chain/index.md；Lua 使用内置宿主文档。参考 native/counter.cpp 与 samples/python_chat。

Agent 可实际读取/上传/搜索项目、改文件、Diff/历史/回滚、调用 API、MCP Tools/Resources、保留任务和追加引导。编辑器用文件哈希拒绝覆盖冲突；二进制产物只读展示，修订以 Base64 保留原字节。上下文提供分段读取和摘要，完整原始历史落盘。源码调用链定位目前是跨文件字面搜索，尚不是 Python/C++ 语义索引引擎。默认技能和工具按语言区分，也可在各工作区分别修改提示词、技能与工具选择；api_call/MCP 通用能力不等于细粒度安全授权。

公网/本机 MCP 使用真实相同 API 内核，支持 Tools、Resources、项目文件资源模板，拒绝无效密钥。游戏工具仍需实际连接和权限，未连接/失败如实报错。不能将“可列出所有工具”误解为“所有业务在所有环境均验证过”。

## 命令链与速率

TXT 放在 插件数据文件/ds_ai_agent/command_txt/，保存时预解析；每文件独立启停、频率与延迟。三位属性为 类型,条件,红石，0 连锁/1 脉冲/2 循环，0 无条件/1 有条件，0 保持开启/1 红石激活；属性继承，独立行 . 分隔链，! 结束周期。有条件依赖上一条真实成功，失败/超时不能冒充成功。

终端 /say A./say B. 自动分段，数字小数、JSON 字符串内的点保留；单条指令照常发送。

导入/导出速率填写自定义正整数，不使用 -1，没有人为 1000 方块截断。实际吞吐仍受游戏响应、区块加载、网络和硬件影响。云端单次传输 32 MB，更大建筑在 APK 本地导入再从云端启动。

## 原作者接入的例外与未完成项

按照用户后续明确要求，插件市场、建筑市场和第 2 个验证服务保留原作者地址，市场凭据与游戏 Token 分开；不向原作者发送控制/设备密钥。作者的商业登录、考试、启动广告、原云模型代理和心跳授权退出新版本流程。

“塞人”服务器队列为独立实现，支持同一账号顺序切换；游戏批量发消息需要实际已连接账号。点赞/私信参考仓库没有可核实的公开协议，目前只有自定义适配器入口，未配置时明确返回错误，不能宣称已经可用。多账号真实进服与 QQ 实际群消息验证受现有身份/凭据限制，结果按实际验收记录交付。

## 性能

使用雷电模拟器内 APK 的计数回调基准，比较复现源码“每次新建 Lua VM、加载源码并回调”的策略、常驻 Lua、C++ 桥接、Python 单条与批处理。每种 3 轮取中位数，详细数值以随附验收说明为准。此测试不是原 APK 整体实测；游戏导入/网络速度不能据此推断，更不承诺整个应用或 Python 快 1000 倍。
