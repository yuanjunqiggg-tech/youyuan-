本补丁是2026-10-22用户澄清“条件满足才加载后续链”的实现，取代同日15:44串行返回方案。入口仍为`雪球菜单_综合功能.txt`，保留原最近盔甲架选择器和111次连续下探，移除用户确认无意义的固定坐标命令方块写入。没有证据证明最近盔甲架实际发生过串用，不能把潜在风险当已发生故障。

## 调度与 API

插件、MCP和客户端共用宿主配置、校验和运行器。旧落盘配置没有`frequency_mode`时保留原上限语义；显式修改`hz`或`interval_ms`默认使用`override`。需要仅限速时传`frequency_mode="cap"`。

Lua插件修改示例：

```lua
chains.configure("雪球菜单_综合功能.txt", {
  hz = 20, frequency_mode = "override"
})
```

MCP的`api_call`示例：

```json
{
  "method": "POST",
  "path": "/api/youyuan/game/call",
  "body": {
    "method": "chains.configure",
    "args": ["雪球菜单_综合功能.txt", {"hz": 20, "frequency_mode": "override"}]
  }
}
```

`override`修改最快主模块，1Hz倒计时、分钟计时维持原周期；条件子模块继承该主频语义。运行中修改会停止旧实例再按原启用状态启动；不会把已停用的链偷偷打开。配置成功不等于服务器实际执行，验收用`chains.get/list`每段`source_hz/target_hz/actual_hz`和世界计分差分共同判断。1000Hz不等于1000TPS或1000视觉帧；实测高频只用于低成本测试链，生产菜单保留20Hz。

## 按需加载和插件调用

`@gate {"command":"真实检测命令","then":"子模块.txt","poll_ms":200}`在条件为真时托管一个子实例；条件结束和父链停止都会取消并等待子实例退出。`else`可以指定条件为假时的模块。条件检测失败或结果未知不会伪装成正常false；递归调用和超过8层调用拒绝。

主入口检测持球、菜单分数、互传、返回请求或雪球实体，活动时才运行菜单核心。回地表和互传倒计时进一步按需加载。补给、区域限制和在线计时继续独立运行。三个下划线辅助TXT保持独立启用关闭；它们被加载的实际状态在`condition_modules`中查看。回收指运行实例停止，解析缓存仍保留。

```text
1,0,0
@plugin {"plugin_id":"自己的插件ID","function":"open_menu","args":["明确的玩家名"]}
```

`@plugin`调用同账号已运行插件的`plugin_api`导出；复用现有`plugin.call`，不重新执行插件源码，也不自动开启已停用插件。参数是字面值，不会自动把字符串`@s`转换为触发玩家。调用目标、账号与权限仍由已有宿主接口校验。
