# 有界读取与Token节省

适用于游园插件开发Agent。参考dsh-ops的有界上下文思路，使用本宿主已有工具；这不是声称安装了dsh原生二进制。无需调用外部服务或额外模型。

1. 先project_list(prefix,offset,limit)找目录，project_search搜索明确关键词；不要开局读取全项目。
2. project_read优先start_line/lines；长行或大JSON用offset/max_chars继续。检查has_more/next_offset等真实返回，不把裁剪内容当全文。
3. 同轮已读且未修改的结果复用。修改或重新登录后核对实际hash/时间/账号范围；不要跨账号复用缓存。
4. Skill只用skill_search定位相关小节，再load_skill(skill,section,offset,max_chars)。先看目录和摘要，不把所有技能正文塞进请求。
5. 外部MCP先mcp_list看目录，再mcp_describe读取选定工具参数；只调用解决当前任务所需工具。
6. 包事件用sense摘要/过滤/最近少量结果；原始大文件留在设备，返回路径、范围与计数。需要精确分析再按需读取。
7. 每个阶段只记录目标、文件、已验证结果、失败、用户限制和下一步。上下文压缩保留这些事实；不能把计划压缩成“已完成”。
8. 可重试只读错误先查连接和参数；写操作结果不明先查状态/回执，不重复发送。不要为省Token删掉必要验证。
9. 使用真实usage统计比较任务质量、输入/输出Token和耗时；估算必须标注。不能承诺固定几倍或百分比节省。

实际作用：减少重复整文件读取、无关技能正文、重复MCP参数目录与过大工具输出，同时保留可定位的完整结果。它不改变模型厂商价格、额度或上下文窗口，也不绕过任何权限。

来源思路：https://github.com/T-Auto/dsh-ops 。宿主现有工具实现仍以游园源码和本次调用结果为准。
