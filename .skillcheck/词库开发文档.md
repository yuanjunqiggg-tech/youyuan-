# Prism 工具箱 · 词库插件开发文档

词库（wordbank）插件是插件的一种类型（`type = "wordbank"`），它**不是 Lua 脚本，而是一份 JSON 配置**。它的作用是：给玩家一组「聊天触发词 → 自动执行的指令」菜单，让不写代码也能搭出实用的机器人指令（发东西、查数据、报坐标等）。

词库插件不需要任何编程、不调用任何 API——只要按本文的 JSON 结构填好触发词和要执行的指令即可。

---

## 一、词库文件在哪

词库插件在 `插件文件/<id>/` 目录下是一个 JSON 文件，文件名叫 `<id>词库.json`（例如 `territory词库.json`）。它和 Lua 插件一样，也有可选的 `manifest.json`（里面 `type` 写 `wordbank`）和 `docs.md`。

你可以在应用里点「创建 → 词库插件」自动生成一个空词库模板，或用编辑器直接改 `<id>词库.json`。

---

## 二、整体结构

最外层是一个对象，只有一个字段 `菜单项`（数组），数组里每一项就是一个"菜单/触发项"：

```json
{
  "菜单项": [
    { "说明": "给钻石", "触发词": ["钻石", "给钻"], "需要的参数(没有则填[])": [], "功能简介": "给玩家 64 个钻石", "触发后执行的指令": ["give [玩家名] diamond 64"], "仅OP可用": false }
  ]
}
```

---

## 三、每个菜单项的字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `说明` | string | 是 | 这个菜单项的显示名（在菜单里给玩家看） |
| `触发词` | 字符串数组 | 是 | 玩家发这些词中的**任意一个**都会触发。可放中文/英文多个 |
| `需要的参数(没有则填[])` | 数组 | 否 | 玩家触发时可带的参数定义，不需要就填 `[]` |
| `功能简介` | string | 否 | 一句话说明这个菜单是干嘛的（给玩家/自己看） |
| `触发后执行的指令` | 字符串数组 | 是 | 触发后按顺序执行的一条或多条游戏指令 |
| `仅OP可用` | boolean | 否 | `true` 表示只有 OP 能触发；`false`（默认）所有人可触发 |

---

## 四、参数（需要的参数）

每个参数是一个对象，定义玩家触发时可以带什么参数、什么类型、缺省值是什么：

```json
"需要的参数(没有则填[])": [
  { "参数名": "目标玩家", "类型": "str", "默认值(没有则为null)": null },
  { "参数名": "数量", "类型": "int", "默认值(没有则为null)": 64 }
]
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `参数名` | string | 参数的名字（仅作提示用） |
| `类型` | string | `int`(整数) / `float`(小数) / `bool`(布尔) / `str`(字符串)，也接受中文 `整数/小数/布尔` |
| `默认值(没有则为null)` | 任意 | 玩家没填这个参数时用的默认值；没有默认值写 `null` |

---

## 五、指令占位符

`触发后执行的指令` 里的每条指令支持两个占位符，执行前会被替换成真实值：

- `[玩家名]` —— 替换成触发这条指令的玩家名。
- `[参数:N]` —— 替换成玩家带的第 N 个参数（N 从 1 起）。按 `需要的参数` 里定义的顺序对应：`[参数:1]` 是第一个参数，`[参数:2]` 是第二个，依此类推。

**示例**：玩家发 `发钱 小明 1000`（触发词 `发钱`，参数定义 目标玩家 + 数量），指令：

```json
"触发后执行的指令": [
  "give [参数:1] diamond [参数:2]",
  "tellraw @a {\"rawtext\":[{\"text\":\"[玩家名] 给 [参数:1] 发了 [参数:2] 颗钻石\"}]}"
]
```

会被替换成：

```
give 小明 diamond 1000
tellraw @a {...[玩家名] 给 小明 发了 1000 颗钻石...}
```

## 六、一个完整示例

一个"查自己位置"的词库插件，`<id>词库.json` 内容：

```json
{
  "菜单项": [
    {
      "说明": "我的坐标",
      "触发词": ["坐标", "我的坐标"],
      "需要的参数(没有则填[])": [],
      "功能简介": "让机器人报出你的坐标",
      "触发后执行的指令": ["tp @s [玩家名] ~ ~ ~", "say [玩家名] 的坐标已标记"],
      "仅OP可用": false
    },
    {
      "说明": "发钻石",
      "触发词": ["发钻石"],
      "需要的参数(没有则填[])": [
        { "参数名": "目标玩家", "类型": "str", "默认值(没有则为null)": null },
        { "参数名": "数量", "类型": "int", "默认值(没有则为null)": 64 }
      ],
      "功能简介": "给指定玩家发指定数量的钻石",
      "触发后执行的指令": ["give [参数:1] diamond [参数:2]", "say 已给 [参数:1] 发放 [参数:2] 颗钻石"],
      "仅OP可用": true
    }
  ]
}
```

---

## 七、注意事项

- **指令需要对应权限**：`give`、`kick`、`gamemode`、`scoreboard` 等指令要求机器人有 OP。机器人无 OP 时这些指令不生效（但不报错）。
- **一条指令里的参数缺省**：玩家没带某个参数时，会用它定义的 `默认值`（`[参数:N]` 换成默认值）；若默认值是 `null` 且玩家没填，该占位符会替换成空。
- **多条指令按顺序执行**：`触发后执行的指令` 里的指令会从上到下依次发送。
- **词库无代码**：词库插件不写 Lua、不调 API，纯 JSON 配置。若需要复杂逻辑（条件判断、跨插件、定时等），请用 Lua 插件类型。
- **菜单展示**：有 `功能简介` 的项，工具箱会在聊天里把它列进菜单供玩家查看。
