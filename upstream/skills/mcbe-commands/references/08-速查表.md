# 八、速查表

> 完整参数表另见内置技能 `bedrock-commands`（command-argument-type / selector-parameter / command-list）。本页只放最常用项和"马上要用"的片段。

## 1. 选择器参数速查

| 参数 | 含义 | 例 |
|---|---|---|
| `@a @p @r @e @s @n` | 全玩家/最近/随机/全实体/自己/最近实体 | `@p` |
| `type=` | 实体类型（可重复排除） | `type=!boat` |
| `name=` | 名称 | `name=光源` |
| `tag=` / `tag=!` | 有/无标签 | `tag=!数据` |
| `family=` | 族（可 `family=!` 排除） | `family=monster` |
| `scores={}` | 分数条件 | `scores={血量=1..}` |
| `hasitem={}` | 持有物品 | `hasitem={item=torch,location=slot.hotbar}` |
| `x,y,z` + `dx,dy,dz` | 区域盒；`dx=0` = 精确点 | `x=~,y=~1,dx=0,dy=0,dz=0` |
| `r=` / `rm=` | 半径 小于/大于 | `r=5` `rm=0.01` |
| `rx=` / `rxm=` | 俯仰角 大于/小于 | `rx=90` `rxm=-90` |
| `ry=` / `rym=` | 偏航角 | `rym=135,ry=-135` |
| `c=` | 数量上限 | `c=1` |
| `m=` | 游戏模式 | `m=!spectator` |
| `l=` / `lm=` | 经验等级 | `l=30` |

**闭区间**：`rx`/`rxm`/`r` 等是闭区间，相邻档位别留缝别重叠。

## 2. 记分板操作

```mcfunction
scoreboard objectives add <名> dummy [显示名]      # 新建
scoreboard objectives remove <名>
scoreboard players set <目标> <项> <值>
scoreboard players add/remove <目标> <项> <值>
scoreboard players operation <目标> <项> <op> <源> <源项>
# op: = += -= *= /= %= > < ><  (>< = 交换)
scoreboard players random <目标> <项> <min> <max>
scoreboard players reset <目标> [项]
scoreboard players reset * <项>                    # 所有人重置某项
```

**假玩家**（不存在的名字）当全局变量：`scoreboard players set ID ID 1`。

## 3. 内置分数（可被 operation 读写）

`x y z rx ry` —— 玩家/实体的坐标与朝向分数。`score.name:"*"` 是读者本人。

## 4. 分数范围写法

| 写法 | 含义 |
|---|---|
| `1..` | ≥1 |
| `..5` | ≤5 |
| `1..10` | 1~10 |
| `5` | 恰好 5 |
| `!1..2` | 不在 1~2（`not=0..2`，网易也见 `not=1..2`） |

## 6. execute 模板

```mcfunction
# 新语法
execute as @a at @s run <cmd>
execute as @a[scores={X=1..}] run <cmd>
execute at @s unless block ~ ~-1 ~ air run <cmd>
execute as @a if score @s X matches 5.. run <cmd>
execute in nether positioned as @s run tp ~ ~ ~
execute as @e[type=boat,c=1] run <cmd>

# 旧语法（网易也支持）
execute @a ~~~ <cmd>
execute @e[type=zombie] ~~~ execute @p ~~~ <cmd>
execute @a[scores={State=5}] ~ ~ ~ titleraw @s actionbar {...}
```

## 8. 常见动作模板

```mcfunction
# 给东西
give @a diamond 1
replaceitem entity @a slot.hotbar 0 snowball 7 0 {"minecraft:item_lock":{"mode":"lock_in_inventory"}}

# 检测并清除
clear @a[hasitem={item=iron_nugget,quantity=1..}] iron_nugget 0 1

# 提示音 + 文字
playsound block.click @a[<选择器>] ~ ~ ~ 1 1
tellraw @a {"rawtext":[{"text":"§a操作成功"}]}
```

## 9. 易错清单

- `as@a` / `@s{...}` 缺空格 → 解析失败。
- `titleraw @s actionbar{...}` 缺空格 → 失败。
- 分数默认 0，不是你想要的初始值——要显式 `set`。
- `@e` 不带 `c=`/`type=` 在分叉里会爆炸。
- 新语法和旧语法不能混在同一词根。
