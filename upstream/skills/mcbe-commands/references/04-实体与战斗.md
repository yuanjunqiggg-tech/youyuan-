# 四、实体与战斗系统

基岩版没有真正的"子弹"实体，社区通用做法是**用船/盔甲架当子弹载体**，用 `execute` 的坐标操作做弹道，用 `damage` 命令结算伤害。

## 1. 船当子弹（鱼竿枪 / 拔刀剑）

原理：玩家用鱼竿"抛出"（基岩版没有投掷 owner，用 `fishing_hook` 最近玩家反查），在玩家眼位召唤一艘船，给船打 tag，每刻用 `^^^` 把它往前推，检测碰撞。

```mcfunction
# 玩家丢出鱼竿 → 最近玩家是射手 → 在眼位前方召唤"子弹"船
execute as @e[type=fishing_hook,tag=!鱼竿] at @s as @p[r=1.8,scores={子弹=1..}] at @s anchored eyes run summon boat ^ ^ ^0.5 facing @s

# 每刻把子弹往前推（不同武器推进量不同）
execute as @e[type=boat,tag=子弹1] at @s run tp ^^^-1.5
execute as @e[type=boat,tag=子弹2] at @s run tp ^^^-3
execute as @e[type=boat,tag=子弹3] at @s run tp ^^^-0.9

# 递增"射程"计时器
scoreboard players add @e[type=boat,tag=子弹] 射程 1
```

## 2. 命中检测（把船抬高再找附近非子弹实体）

关键技巧：把子弹**抬到 +300 高度**再检测，避免撞到地面/玩家本体；命中的目标用 `positioned ~ ~-300 ~` 拉回原高度结算伤害。

```mcfunction
# 命中判定：子弹射程达标 + 附近有非子弹实体
execute as @e[scores={射程=5..},type=boat,tag=子弹] at @s positioned ~~-300 ~ if entity @e[type=!boat,type=!item,c=1,r=1.5] run tag @s add 击中

# 结算伤害（伤害命令的"施害者"必须是实体）
execute as @e[scores={射程=5..},type=boat,tag=子弹1,tag=击中] at @s positioned ~ ~-300 ~ run damage @e[r=1.5] 5 entity_attack entity @p[tag=鱼竿枪]
```

命中/未命中反馈：

```mcfunction
execute as @a[tag=鱼竿枪] if score @s s = @e[type=boat,tag=击中] s run tellraw @s {"rawtext":[{"text":"§pHit !!"}]}
execute as @a[tag=鱼竿枪] if score @s s = @e[scores={射程=60..},type=boat,tag=子弹] s run tellraw @s {"rawtext":[{"text":"§7Miss"}]}
```

## 3. 伤害与血条

```mcfunction
# 直接伤害：damage <目标> <数值> <伤害类型> <施害者>
damage @e[r=1.5] 15 entity_attack entity @s
damage @e[r=1.5] 30 entity_explosion entity @s

# 血条：用记分板存血量，用 rawtext 画（空槽不显示 + 分档）
scoreboard objectives add 血量 dummy
scoreboard players set @a[scores={血量=..0}] 血量 0
```

> 血条渲染用 `titleraw actionbar`，见 `02-rawtext.md` 的进度条写法。血量分 20/40/60/80 四段决定点亮几个方块字符。

## 4. 怪物/实体效果批量处理

```mcfunction
# 随机给怪物加不同 buff（random 命令）
scoreboard players random @e[family=monster,type=!ender_dragon,type=!minecraft:wither,tag=!怪物] s 1 8
tag @e[family=monster,type=!ender_dragon,type=!minecraft:wither] add 怪物
effect @e[family=monster,scores={s=1}] regeneration 15 2 true
effect @e[family=monster,scores={s=2}] speed 15 3 true
```

注意：**`random` 会给每个目标随机一个值**，配合 `scores={s=N}` 就能做"每只怪随机一种 buff"。

## 5. 玩家自身状态（生命/无敌）

```mcfunction
# 用一个记分板当"血量"，扣到 0 则 kill
execute as @a[scores={Blood=..0}] run kill @s
scoreboard players remove @a[scores={Blood=1..}] Blood 1
```

网易环境有真实 `damage` 命令与 `health` 组件，但租赁服常用"记分板血量"做完全可控的战斗系统（见地铁指令集的 `Blood` 记分板）。

## 6. 射线 / 复杂弹道（坐标链技巧）

用一长串 `rotated as <辅助实体> positioned ^^^<step>` 把坐标沿一条曲线推出去，用来精确放粒子、放结构、做扇形/螺旋弹幕：

```mcfunction
execute as @e[tag=释放] at @s positioned ^^1^2.5 \
  rotated as @e[tag=箭,c=2,type=boat] positioned ^^^0.25 \
  rotated as @e[tag=箭,c=2,type=boat] positioned ^^^0.5 \
  rotated as @e[tag=x,type=boat] positioned ^^^1 \
  run structure load 箭 ~~~
```

要点：每次 `rotated as` + `positioned ^^^` 都是一次"沿当前朝向前进 N 格"。辅助实体（tag=x/y/z 的船）用来分段改变方向，实现弯曲弹道。

## 7. 常见坑

| 症状 | 原因 |
|---|---|
| 子弹打到玩家自己 | 命中检测没排除 `type=player` / 发射者本人 |
| 子弹卡在地面 | 没把检测点上抬（`positioned ~~300 ~`） |
| 伤害不生效 | `damage` 的施害者参数给了非实体，或伤害类型拼错 |
| 弹道乱飞 | `^^^` 依赖朝向，忘了先 `rotated as` |
| 船子弹数量爆炸 | 没在命中/超射程后 `kill` |
