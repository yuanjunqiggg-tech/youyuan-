# 三、菜单与状态机

基岩版没有 GUI API，所有"菜单"都是**用记分板 + 玩家朝向 + actionbar 文本**模拟出来的。核心思想：一个玩家有一个"当前菜单状态"分数，朝向选择光标，丢物品/抬头低头做确认。

## 1. 雪球菜单骨架（视野选择型）

用**丢雪球**打开菜单，用**玩家俯仰角**选择项，用**抬头/低头**确认/取消。

```mcfunction
# —— tick 循环，每刻执行 ——

# 1) 检测刚丢出的雪球：给最近玩家 +1，并打标记
execute as @e[type=snowball,tag=!snow] at @s if entity @p[r=1] run tag @s add menu
tag @e[type=snowball] add snow
execute as @e[type=snowball,tag=menu] at @s run scoreboard players add @p[r=0.1] mu 1
execute as @e[type=snowball,tag=menu] at @s run playsound block.click @p[r=1] ~ ~ ~ 12 0.8
kill @e[type=snowball,tag=menu]

# 2) 当前朝向 → 菜单项编号 s（-90..90 分 9 档，每档 20 度）
scoreboard players set @a[rxm=-90,rx=-70] s 1
scoreboard players set @a[rxm=-69,rx=-50] s 2
scoreboard players set @a[rxm=-49,rx=-30] s 3
scoreboard players set @a[rxm=-29,rx=-10] s 4
scoreboard players set @a[rxm=-9,rx=10]  s 5
scoreboard players set @a[rxm=11,rx=30]  s 6
scoreboard players set @a[rxm=31,rx=50]  s 7
scoreboard players set @a[rxm=51,rx=70]  s 8
scoreboard players set @a[rxm=71,rx=90]  s 9

# 3) 抬头确认（pitch 顶部）→ 进入所选子菜单；低头取消 → 关闭
scoreboard players set @a[scores={mu=2,s=5,not=2..}] mu 0   # 例：第5项是"原地飞升"
```

要点：
- **`rx` = pitch 上限，`rxm` = pitch 下限**，区间是闭区间，相邻档位不要留缝也别重叠。
- 打开菜单用"丢雪球 + 最近玩家"反查投手（`@p[r=1]`）——这是基岩版没有投掷者 owner 时的通用近似。
- `mu` 是"人机交互步"状态：0=无菜单，1=一级菜单，4/6/8…=二级菜单，2=确认动作。

## 2. 状态机模式：一个分数当状态

```mcfunction
# 初始化
scoreboard objectives add State dummy

# 状态 1=无雪球, 2=哑巴说话, 3=生存飞行, 4=灵魂出窍, 5=黑名单, 6=禁用雪球, 7=访客
execute if entity @a[scores={State=1..}] run <对应的连锁命令>
scoreboard players set @a[rxm=88,scores={State=3}] State 0   # 低头 → 退出状态3
```

**原则**：
- 每个状态一个整数；进入/退出各写一条赋值。
- 退出条件用选择器表达（`rxm=88` = 低头），不要用 if 嵌套。
- 状态机 + tag 双轨：分数适合"唯一状态"，tag 适合"多个并存的属性"（如 `vip`、`末地`、`坐标`）。

## 3. 冷却（cooldown）

```mcfunction
# 开枪后设冷却，每刻递减
scoreboard players set @s 冷却 40
execute as @a[scores={冷却=1..}] run scoreboard players remove @s 冷却 1

# 只有冷却 <= 0 才能开火
execute as @a[scores={冷却=..0}] if entity @s[tag=鱼竿] run <开火>
```

## 4. 手持物品检测（不需要 GUI）

```mcfunction
# 手上拿雪球时做某事
scoreboard players set @a[hasitem={item=minecraft:snowball,location=slot.weapon.mainhand}] tk 1

# 背包里有铁粒 → 装弹
scoreboard players add @a[scores={子弹=..63},hasitem={item=iron_nugget,quantity=1..},rx=-88] 子弹 1
clear @a[hasitem={item=iron_nugget,quantity=1..},rx=-87] iron_nugget 0 1
```

## 5. tag 门控（一次性触发）

```mcfunction
# 成就/首次触发：条件满足且还没有 tag → 触发并打 tag
execute as @a[hasitem={item=crafting_table,quantity=1..},tag=!av1] run tellraw @a {"rawtext":[{"text":"§h取得进度『这是?工作台!』"}]}
tag @a[hasitem={item=crafting_table,quantity=1..},tag=!av1] add av1
```

## 6. 常见失效原因

| 症状 | 原因 |
|---|---|
| 菜单不显示 | 玩家分数没进正确的 `mu` 状态；或 tick 没挂上 |
| 选中项错位 | `rx`/`rxm` 档位有空隙或重叠 |
| 每刻重复触发 | 触发后忘记改状态/tag（如确认动作没把 `mu` 归零） |
| 丢雪球没反应 | `@p[r=1]` 没抓到投手（雪球飞太快/太远），需加大半径或换反查方式 |
| 抬头低头同时命中 | 角度阈值写反/重叠，注意基岩版 pitch 是 -90（抬头）到 90（低头） |
